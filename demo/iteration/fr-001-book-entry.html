FR-001 · v2 当前 · 需求规则

1 业务目标与入口

代发剪辑手在 PC 端「剪辑供稿 / 上传稿件」第二步「填写并选成片流程」检索书籍、补齐空字段；不改第一步交互。

2 检索与补空

  • 名称、ID 均支持当前项目系书库模糊检索，最多20条；空态「暂无结果」。
  • 点选时当前搜索字段（名称或 ID）直接更新为候选对应值；其他字段仅为空时补入，同一记录补出，其他已有值不覆盖。
  • 名称、ID、类型、链接选后均可手动修改。

3 校验与边界

  • 仅第二步点「下一步」校验；无异常直接进入第三步，输入 / 失焦 / 点选不弹校验窗。
  • 字节系、知乎系异常可「取消」或「继续提交」；海外短剧、海外小说异常只能「关闭」并留第二步。
  • 其他项目不做本 FR 书籍校验。第三步最终提交不再次拦截。
  • 比较前去掉首尾空格，其他字符完全一致；不忽略大小写、协议、query 或尾斜杠差异。空值 / 无记录暂按未匹配 [待确认]。
  • 名称是否额外参与匹配 [待确认]；当前按项目系只校验 ID 或链接。
  • 查库失败独立显示系统异常，不视为填错；保留已填内容，关闭后留在第二步，海外项目不因查库失败按错填拦截。
