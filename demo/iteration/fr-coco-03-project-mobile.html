团队项目数据 · 完整需求规则 V4.2

适用于当前手机 H5 Demo。展示为模拟数据，金额、订单和成员信息以服务端真实数据为准。

01 页面与功能

位置 / 功能规则（数据源与操作）
团队数据首页 / 项目数据点击进入项目数据首页；项目入口为可点击导航。
项目数据 / 项目奖励构成按累计、今日、昨日切换；最多显示奖励前5项目及更多项目；更多项目仅用于图表聚合，不作为项目列表项。数据源：当前团队项目奖励汇总。
项目数据 / 项目排行榜展示具体项目名称、项目Icon、累计/今日/昨日团队奖励及对应出单流水；支持六种降序排序，切换列表排序不影响饼图排名。项目Icon由后台配置，缺失时显示兜底图。
项目数据 / 成员排行榜汇总当前帐号有权查看的成员在全部项目产生的有效出单量、有效出单流水和团队奖励；按成员去重，展示前100名。支持用户ID/昵称搜索、五类成员关系筛选、五种时间维度下拉和三种排序下拉。
项目详情 / 双排行榜保留成员奖励排行、成员出单排行两个独立Tab；均只统计当前项目；奖励榜按团队奖励降序，出单榜按有效出单流水降序，并显示有效出单量；每榜最多100名。
项目详情 / 筛选用户ID/昵称搜索；成员关系五选项：全部、直属、间属、直属团队、间属团队；时间Tab：累计、今日、昨日、近7日、近30日。两个榜单共用筛选，不再提供排序下拉。
项目详情 / 页头保留项目名称、导航与排行榜，不恢复原顶部四项统计卡片。

02 成员点击与详情

入口点击规则
全项目成员排行榜打开原有成员详情抽屉；显示所选周期的全部项目汇总、有效出单量、出单流水、团队奖励和分项目明细。抽屉数据必须与列表筛选周期一致。
单项目成员奖励排行打开现有「成员产生奖励详情页」，传递成员ID及当前项目ID；Demo未接入实际业务页时仅显示规则提示。
单项目成员出单排行同样打开现有「成员产生奖励详情页」，传递成员ID及当前项目ID；不使用全项目汇总抽屉。
备注成员卡片不展示备注按钮，不保留备注操作。

03 统计口径与权限

字段 / 场景规则
团队奖励成员为当前查看团队产生的有效团队奖励，非成员个人收入；服务带动奖励纳入团队总奖励，不与其他归属重复计入。
成员关系邀请关系独立于奖励归属；加入导师团不改变邀请关系，后续奖励按服务带动归属统计，历史归属保持原口径。
有效出单量按所选周期统计有效订单笔数；无效、撤销或不符合结算口径订单不计入。
出单流水有效订单交易金额，单位元；不代表成员个人收益。跨项目汇总需依据订单唯一ID防重复计数。
时间维度累计为业务累计有效数据；今日/昨日按业务时区自然日；近7日/近30日按统一服务端统计窗口计算，列表和详情一致。
权限成员出单流水与订单量等敏感经营数据仅向明确授权帐号开放；前端控制展示，后端按帐号、团队、项目范围再次校验，不能仅靠隐藏组件。
无数据/异常搜索或筛选无结果显示空状态；接口失败显示重试；不得将接口异常误显示为0收益。

验收重点：项目详情双Tab完整；成员点击按入口分流；全项目数据去重；时间筛选联动；项目Icon正常兜底；375px H5无横向溢出。
