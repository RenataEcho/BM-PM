# 批量传订单 · DESIGN

## 依据与范围

- 业务线：右豹主业务（youbao）。界面类型：后台管理。
- 需求草稿与交互规则见同目录 `需求单.md`、`EXPERIENCE.md`。
- 仓库内现有后台规范 `docs/design/admin-ui-spec.md` 不存在，不能据此声明后台界面完整合规。
- 可复用的需求池组件规范来自 `demo/iteration/component-spec-demo.html`，包括 `.btn`、`.mini-table`、`.tag-*`、`.modal-overlay`、`.drawer` 等。正式研发页面应以后台规范为准，不将迭代外壳渐变背景用于后台业务页。

## 页面结构

1. 专项需求侧栏中提供「批量传订单」入口。
2. 页头使用页面标题和一句用途说明。
3. 查询表单包括文件名、项目、处理状态、审核状态，以及查询和重置操作。
4. 批量上传模块居中呈现附件入口；选择多个表单后，在「本次上传订单」区展示文件名、项目识别结果、编辑和删除。
5. 每条表单只允许选择一个项目。所有文件确认后，以一个「一键处理」按钮统一提交。
6. 订单处理列表置于上传模块下方；订单分发列表位于处理列表之后。
7. 「一键审核分发」确认弹窗说明：审核成功后后台把该组订单分发到对应项目订单列表，订单状态变为已审核。分发重传若检测到订单未审核，再用居中弹窗二次确认。

## 视觉与组件

- 复用仓库组件规范的主要按钮、状态标签、表格和确认弹窗。
- 沿用当前右豹后台原型的白色工作区、浅灰背景、紧凑筛选栏、清晰表格行分隔。
- 处理完成、处理中、异常和待审核需使用文字标签及颜色共同表达，不只用颜色传达状态。
- 上传队列的选择入口与批量处理按钮层级分明；清单的逐行操作只用于编辑项目和删除文件。
- 小屏时表格保持可横向滚动，上传清单字段换行，主要按钮可见。
- 分发列表只记录审核成功的订单组；成功行编辑单元格留空，分发失败行提供重传入口。
