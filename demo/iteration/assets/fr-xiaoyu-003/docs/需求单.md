# 需求单

业务线：右豹主业务（youbao）

需求名：批量传订单

全局编号：FR-XIAOYU-003（用户已确认）。

状态：待开始

## 需求概述

后台在「专项需求」下增加「批量传订单」入口，面向品牌项目。运营人员可批量选择订单表单、逐条指定项目、统一处理订单，查看处理与审核状态，并将审核通过的订单分发至对应项目订单列表。

本次交付本地可交互原型、交互约定、界面说明、开发说明和业务路径图。用户已授权登记到右豹主业务并按 product-yu 分支上传。

## 使用者与入口

- 使用者：后台运营人员、订单审核人员。
- 入口：右豹 2.0 后台 → 专项需求 → 批量传订单。
- 本需求只覆盖后台批次处理和订单分发管理。

## 用户路径

1. 在批量上传区选择一个或多个 CSV、XLS、XLSX 表单。
2. 系统按上传文件名映射项目。未匹配时，操作人员可编辑该条记录，并从已有项目中单选项目名称。
3. 在「本次上传订单」清单检查文件与项目，允许删除单条表单。点击唯一的「一键处理」将全部待处理表单提交到下方订单处理列表。
4. 订单处理列表展示每份表单的文件名、项目、上传时间、处理状态、处理进度、成功和失败数量、订单量与金额、审核状态和操作。
5. 处理完成的表单可执行「一键审核分发」，审核通过后由后台将这一组订单分流到对应项目订单列表。
6. 部分失败、处理失败表示部分订单未上传成功，或订单与关键词的归因关系校验异常。操作人员可下载失败文件查看失败原因，修订后重传失败表单，结果更新在原表单记录。
7. 处理中表示订单仍在校验。处理未完成时不允许一键审核分发。
8. 分发列表每组审核成功的订单表单记录一行。展示文件名、项目、分发时间、分发状态、订单状态和编辑。分发成功时编辑字段为空；分发失败时可重传。
9. 分发失败可由接口报错或已审核订单分流异常引起。重传更新原分发组，不新增重复组。若发现审核未完成，重传前显示二次确认。

## 页面字段

### 订单处理列表

文件名（可下载源文件）、项目、上传时间、处理状态、处理进度、成功数、失败数、订单量、订单金额、审核状态、操作。操作包含一键审核分发、下载失败文件、重传失败表单。

### 订单分发列表

文件名、项目、分发时间、分发状态、订单状态（已审核／未审核）、编辑（仅分发失败时提供重传）。

## 禁止条件

- 处理中、部分失败、处理失败的订单表单不可一键审核分发。
- 未匹配项目且未手动选择项目的表单不可一键处理。
- 订单审核未完成时，分发失败记录重传前必须再次确认。
- 一个上传表单只能映射到一个项目。

## 研发说明

文件名映射项目由前端展示映射结果并允许人工单选修正。审核通过后的订单分流由后台完成。页面原型只展示流程，不接真实接口。上传接口、项目映射规则、处理任务状态、进度来源、失败数据结构、订单分发接口和幂等策略待研发评审确认。

## 待确认

1. 文件名与项目名称的映射规则、别名配置和冲突处理。
2. 一键处理是并行创建每个文件任务，还是将整批作为一个任务提交。
3. 部分失败表单内成功订单是否允许脱离原表单单独审核分发。
4. 订单量、订单金额的口径，以及失败重传后原成功订单是否去重合并。
5. 重传分发失败记录时，是否需要重新审核已审核订单，以及「未审核」二次确认的文案与权限要求。
6. 上传与重传的大小、行数、文件类型及保留期限限制。
7. 分发失败的判定条件、自动重试策略及失败原因展示。
8. 后台 UI 正式规范文件当前未随工作区提供，界面样式需按仓库正式规范复核。
