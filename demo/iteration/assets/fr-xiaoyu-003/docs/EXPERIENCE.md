# 批量传订单 · 交互场景

本文件记录用户可在本地原型中体验的场景。示例数据和状态为前端演示，不表示已接入后台服务。

## 场景一：批量选表单与确认项目

1. 点击上传区的「选择附件」，选择多个 CSV、XLS 或 XLSX 文件。
2. 文件名能映射已有项目时，清单显示映射结果。
3. 文件名无法映射时，该行提示「未匹配项目」，点击「编辑」后从项目列表单选一个项目并保存。
4. 未映射文件未完成项目选择前，「一键处理」不可用。
5. 清单支持逐条删除，也可继续添加文件。

## 场景二：一键处理和进度查看

1. 点击唯一的「一键处理」将待处理清单里的全部文件提交到订单处理列表。
2. 每个表单在列表中形成独立记录，显示项目和处理进度。
3. 处理中表示订单仍在校验并显示动态进度；完成显示 100%；处理失败显示异常。
4. 处理成功、部分失败、处理失败和处理中分别保留不同状态，不以进度值替代处理状态。

## 场景三：处理完成后的一键审核分发

1. 处理完成表单可点击「一键审核分发」并打开确认弹窗。
2. 弹窗展示文件、成功数、失败数和金额，并说明后台将该组订单分发至对应项目订单列表。
3. 处理中、部分失败和处理失败表单的一键审核分发按钮禁用。
4. 确认后由后台审核该表单订单并发起分发。分发列表按订单组记录一行。

## 场景四：部分失败或处理失败的表单

1. 部分失败、处理失败表示部分订单未上传成功，或订单与关键词归因关系校验异常。
2. 操作人员下载失败文件，查看每行失败原因，修订后重传失败表单。
3. 原表单记录显示处理中和新的校验进度，完成后更新原记录的状态、成功数、失败数和订单统计。

## 场景五：分发失败订单组重传

1. 分发列表只记录审核成功的订单组，每组表单一行。
2. 分发成功记录的编辑单元格为空；仅分发失败记录显示「重传」。
3. 分发失败可能由接口报错或已审核订单分流异常引起，重传更新原分发组。
4. 若重传校验发现订单审核未完成，先二次确认；取消不更改记录。
5. 分发结果不改变订单审核状态。
