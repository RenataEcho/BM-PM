开发说明

01　模块展示

  1. 在工具配置关联的项目详情页展示推荐工具；未登录也正常显示。
  2. 每项展示工具图标、名称和后台动态返回的标签，最多展示 3 个标签。
  3. 命中数量 > 5：模块右上角显示“更多”，点击进入工具列表；数量 ≤ 5：不显示“更多”。
  4. 当前 UX 每次展示最多 5 个工具，零匹配隐藏模块，卡片样式复用上方社区列表。

02　第一步：校验使用端口

点击工具后，先判断当前访问端是否在该工具配置的使用端口范围内。

不匹配 → 提示后结束

请前往 {端口名称} 使用

名称根据后台多选端口动态拼接，例如：请前往 ios/安卓 使用。不继续判断积分。
匹配 → 进入使用门槛判断

03　第二步：校验使用门槛

  1. 完全免费：直接按工具链接进入工具页。
  2. 积分使用，用户积分 ≥ 工具所需积分：直接进入工具页，积分相等也允许进入。
  3. 积分使用，用户积分 < 工具所需积分：显示积分不足弹窗。

04　积分不足弹窗

该工具所需积分xx，您当前积分不足，是否前往积分兑换？
  • xx 使用当前工具所需积分。
  • 取消：关闭弹窗；前往兑换：进入积分兑换页面。
  • 当前 UX 支持点击蒙层关闭，底层页面不跳转。

05　待确认边界

未登录点击积分工具后的登录与余额获取流程、未配置任何可用端口时的提示，仍待确认。当前演示对此显示待确认提示。

01　新增字段：展示项目

  • 工具管理新增“展示项目”下拉多选字段，选项来自线上项目。
  • 支持新增保存、编辑回填及清空选择。
  • 未勾选任何项目：该工具不在任何项目详情页展示。
  • 仅勾选项目 A：只在项目 A 详情页匹配该工具。

02　配置与返回数据

  1. 展示内容：工具名称、图标、动态标签集合；前端最多展示 3 个标签。
  2. 访问校验：使用端口集合，支持多个可用端。
  3. 使用门槛：完全免费 / 积分使用；积分工具返回所需积分。
  4. 跳转信息：工具使用链接。
  5. 列表信息：当前项目命中数量，供前端判断是否展示“更多”。

以上为数据职责说明，具体接口字段名与结构由研发约定。

03　匹配及判断顺序

  1. 按当前项目筛选“展示项目”已勾选该项目的工具，不将未关联工具展示给前端用户。
  2. 提供工具的使用端口，当前访问端不匹配时进入端口提示分支。
  3. 端口匹配后，按使用门槛判断；完全免费直接进入工具页。
  4. 积分使用时，以当前用户积分与该工具所需积分比较：大于或等于允许进入，小于提示兑换。

04　范围与待确认

本需求明确使用前的积分判断与跳转，不新增积分扣除时机、计费方式或每日免费次数规则。

待确认：未登录积分读取方式、空端口处理、多端名称顺序、同权重排序。当前 UX 的排序、零匹配隐藏和蒙层关闭行为需作为演示约定核对。
