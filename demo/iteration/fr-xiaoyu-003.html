管理后台前端

新建项目统一归属于“小程序推广计划”，项目方管理仅配置二级页面的项目名称、项目ID、展示状态、项目说明和排序。一级赛道和短剧链接由其他后台接口统一维护。任务管理获取撮合平台任务数据，流水管理获取撮合平台订单数据。比例设置同时支持前端展示和原始订单拉取后的达人收益计算，分佣计算规则解释公式与用户入账方式。

  • 项目 → 小程序推广计划下提供项目方管理、任务管理、分佣设置和流水管理。任务列表默认展示同步任务，按后端结果刷新归属和上架状态。
  • 比例设置包含通用和任务自定义两页。已创建规则通过删除后重建调整，删除后原规则立即失效。

后端

  • 查询合作小程序任务 ID，再按 ID 拉取详情，按任务 ID 去重入库。ID 接口单次查询时间范围最长 7 天。手动新增时用任务路径查详情，取得 ID 后走同一入库流程。
  • 后端处理任务与项目方关联及批量上架。重新同步更新抖音任务数据，保留右豹归属与上架配置。
  • 有效任务自定义规则优先，未命中按订单类型和右豹用户身份匹配通用规则。删除时旧规则失效，新规则按创建时间生效。自定义规则删除后、重建前按通用规则计算。历史流水保留实际采用的比例及计算方式。
  • 任务统计和流水逐项映射文档支持的返回参数。接待数、投稿数、逐笔订单及用户映射等字段的数据来源待确认。

终端前端

  • 展示后端返回的已上架任务。发现页进入项目列表，项目页展示项目方和任务卡片，任务详情展示结算方式、右豹前端分成和抖音分成，并提供参与入口。
  • 达人在抖音完成绑定、接单和挂链投稿。右豹到抖音的正式跳转与二维码对接方式待确认。

计算与发放说明

比例与公式的关系

一条分佣规则同时保存适用范围、结算比例、前端展示比例和计算方式。结算比例作用于计算基数；前端比例仅展示，不重复参与计算。新增弹窗中的试算只使用当前未保存的表单值。

如何确定佣金

任务自定义规则优先；未命中时按订单类型和用户身份匹配通用规则。

按官方流水计算：试算基数 × 用户结算比例。

按机构分佣后计算：试算基数 × 机构分成比例 × 用户结算比例。

试算暂用订单净额并四舍五入到分，正式金额字段与公式待确认。前端展示比例用于任务页展示，收益计算使用结算比例。

动态试算如何变化

输入净额或结算比例后实时重算；选择按机构分佣后计算时启用机构分成，并新增机构分佣计算步骤。选择按官方流水计算时禁用机构分成。空值和越界输入不输出金额，0 是有效值。修改前端比例只更新展示预览。

如何给到用户

应得佣金 → 结算校验 → 关联右豹用户 → 按确认后的发放条件入账。保存规则不触发打款，试算金额不等于已到账金额。未命中任何规则时标记待配置，不默认按 0 元结算（本版草稿建议）。

通过订单、任务和达人映射关联右豹用户 ID。到账账户、发放条件、到账时间和退款扣回规则待确认。

何时生效

新建规则按创建时间生效。删除自定义规则后按通用规则计算，历史流水保留原结果。
