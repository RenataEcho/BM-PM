# 从 YBDD2.0 带过来的规范

本目录是 **写作与验收约定**，不是右豹某条功能的档案。历史 PRD / FR 页面仍留在旧仓。

| 文件 | 用途 |
|---|---|
| `需求单.md` | 同事提需求时复制填写 |
| `需求输出规范.md` | 新增需求的步骤、提示词、落盘位置和编号 |
| `ITERATION-FR-GUIDE.md` | FR Demo 页结构、流程图、规则抽屉、组件 class |
| `design/移动端设计规范.md` | C 端主视觉：橙系、字体、画布、通用手机组件 |
| `design/c-end/DESIGN.md` | 旧「2.0优化」增量样例，不当品牌真源 |
| `design/iteration-shell/DESIGN.md` | 迭代 Demo 外壳（玻璃拟态 B 端） |
| `design/iteration-shell/EXPERIENCE.md` | 迭代台 IA、三模板、规则抽屉行为 |
| `design/admin-ui-spec.md` | 管理后台 UI 规范（玻璃拟态、明暗主题） |

组件 class 从 `demo/iteration/component-spec-demo.html` 复制，不要另起一套按钮/弹窗/流程图样式。
