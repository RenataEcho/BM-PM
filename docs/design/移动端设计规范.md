# 移动端设计规范

> **用途**：C 端 App / 手机 Demo 的主视觉与通用组件。新 FR 不另起配色。  
> **不是**：某一刀需求的页面合同。增量视觉写当天的 `ux-*/DESIGN.md`，只记本刀差异。  
> **Token 来源**：右豹创作者端 2026-10（橙系 + 数据页黑金）。  
> **对照**：管理后台见 `docs/design/admin-ui-spec.md`；迭代 Demo 外壳见 `docs/design/iteration-shell/DESIGN.md`（蓝紫玻璃，不要混进手机画布）。

**冲突：** 本文件管品牌与通用组件。本增量 `DESIGN.md` / `EXPERIENCE.md` 只覆盖本刀页面。和 Demo 冲突时改 Demo。

---

## 1. 主视觉

移动端优先。默认叙事是 **可赚、可学**：浅灰底 + 白卡片 + **暖橙**做主识别。

| 层 | 怎么用 |
|---|---|
| 品牌橙 | 主 CTA、底栏选中、关键收益数字、选中 Tab |
| 浅灰底 / 白卡片 | 默认页面与模块；阴影很轻，不走玻璃拟态 |
| 暖橙软底 | 推荐理由、工具 chip、轻提示条 |
| 克制黑金 | **仅数据 / 资产 Hero**，作用域锁死，不铺全 App |

营销数字可以高饱和橙。分析/资产页用深底金字，和首页「发现」分开。

不要把迭代台的蓝紫、管理后台的玻璃拟态抄进手机框。

## 3. 字体

栈：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", Arial, sans-serif`

| 层级 | 大小 / 字重 | 用途 |
|---|---|---|
| 页标题 | 17px / 900 | 榜单标题、页名 |
| 模块标题 | 15px / 800 | 卡片主标题、项目名 |
| 行标题 | 13px / 800 | 列表主行 |
| 正文 | 12px / 400，行高 1.5 | 说明；金刚区标题可用 12px / 600 |
| 辅助 | 9px / 500 | 副文案、chip |
| 收益数字 | 16px / 800，色 brand-orange | 列表/卡片上的金额 |
| 数据 Hero 数字 | ~43px / 800 | **仅数据页** |

数字除颜色外必须保留字重差，不能只靠橙色区分。

## 4. 画布与间距

- 逻辑宽 **390px**，桌面预览居中；外壳圆角 24px + 外阴影。
- iframe 设计稿按 375×812 画，框内 `transform-origin: 0 0` 缩放。
- 左右 gutter **12px**；模块间距 **12px**。
- 底栏高 **74px**，含安全区约 **86px**。主路径页面不要再叠一层贴底通栏。
- 圆角：控件 8px、卡片 12–16px、Sheet 顶 20px、胶囊 9999px。

---

## 5. 通用组件

### 底栏

高度 74px。选中 brand-orange，未选中 `#758096`。全屏子页（详情、学院等）隐藏底栏，返回后恢复。

### 卡片

白底、轻阴影。同一模块里的入口（如金刚区）做在**一张**白卡片里，不要每颗入口一张浮层。

### 搜索

全圆角胶囊，不要做成方输入框。

### Chip / 标签

推荐工具等用浅橙底 + 橙边 + 橙字（约 `#fff5f1` / `#ffe5dc` / `#f06446`），字号可到 8.5px。不要和标题同一行抢位。

### 快捷入口（金刚区形态）

四列等分。图标底板 44×44、圆角 14px，**方圆不是正圆**。底板暖色毛玻璃：半透明白、顶高光、底边暖橙内阴影。符号是填色图形，不是细线空心 icon。标题四字要完整露出。

具体有哪几个入口、跳哪，写在当条 FR 的 DESIGN / EXPERIENCE，不写在本规范。

### Bottom Sheet

顶 drag bar `#e4e6eb`；圆角 20px 20px 0 0；最高约 72%。遮罩点击关闭。工具 Sheet z-index ≥ 900。若有「为什么推荐」，用独立浅橙块，不要和描述灰字混在一起。

### 轻提示（手机框内）

白卡片、圆角 16px、左右留白。一张卡只说一件事。标题 17px/800 用正文色，不用红。主按钮全宽品牌橙。不要套迭代台 400px 确认弹窗，不要警告三角。

### 客服悬浮（若需要）

暖杏底 `#fff4e8`、圆角 16px，浮在内容上、左右留白，**不要贴底通栏**。二维码放弹层，不铺在栏上。

### 数据 Hero

仅数据页：深棕黑渐变、底圆角约 `0 0 30px 30px`、金色分割。空态 / 示例用浅金底 `#fffaf2`。示例金额必须标明演示，不装成真账户。

---

## 6. 动效与反馈（默认）

- Sheet：自底滑入；点遮罩关闭。
- Toast：短反馈，手机框或 Demo 页均可，不假装写库成功。
- 轮播（若有）：选中点 brand-orange，未选中浅橙；点击优先于自动切帧。

---

## 7. Do / Don't

**Do**

- 新 C 端画面只使用上表 token。
- 项目/收益先于工具；工具放 chip 或底行。
- 黑金锁在数据页。
- 手机 Demo 嵌在 FR 页内，一屏能看到场景和至少一台完整手机。

**Don't**

- 不要另起蓝色、绿色作为 C 端主色。
- 不要把管理后台玻璃拟态、迭代台蓝紫用进手机框。
- 不要把数据 Hero 样式套到首页、变现、工具。
- 不要把快捷入口图标做成正圆细线。
- 不要在首页默认放路径气泡、绑定邀请码（产品没点名就要）。
- 不要在本文件里写死某一版首页模块顺序或入口文案——那是增量 DESIGN 的事。
