## Intent

业务线：右豹主业务。补齐团长发送留言后查看记录的入口与页面，让团长能核对给哪个直属下级发过什么内容及发送结果。沿用 FR-wen-003 的现有手机稿、内存记录和发送快照，补充列表与只读详情，并同步本需求文档和规则说明。

## Implementation Notes

- 原需求将移动端记录页列为非目标，本次用户明确要求补入，按同一 FR 的修订处理。
- 团队成员列表提供总入口；直属对象卡片提供按对象查看入口；历史读取不依赖发送开白状态。仅展示当前团长自己的记录，按时间倒序，支持对象搜索与发送状态筛选。
- 复用当前记录模型，不增加接口、持久化或消息已读回执；未知结果仍走原查询交互，不能伪造成功记录。详情展示发送快照，不提供重发、撤回或编辑。
- 工作区已有 FR-wen-005 等未提交修改，保持原状，仅处理 FR-wen-003 文件。用户已授权继续此项可逆 Demo 修改。
- 验证覆盖发送后记录更新、总入口及对象入口、详情返回、搜索与空态、关闭开白后的历史可见性、宿主与独立页面同步。

- 已完成：团队成员页头总入口、直属对象记录入口、本人记录倒序列表、对象搜索与状态筛选、只读快照详情、空态、规则说明及 SVG 流程追溯节点；发布稿与 mockups 副本同步，Demo 版本更新为 v2。
- 验证：Node 语法检查、git diff --check、手机脚本与两个 HTML 副本一致性通过。浏览器实测发送成功后新记录置顶、详情正文、搜索空态、重置及对象入口。独立审查回归：失败异步回包后记录从 2 条刷新为 3 条，组合筛选及滚动位置保持。
