## Foundation

这是右豹 PC 端代发剪辑手的上传稿件流程，使用迭代外壳，桌面优先。交互行为继承现有组件；视觉引用 `DESIGN.md` 的 `{colors.*}`、`{typography.*}`、`{rounded.*}` 和 `{components.*}` token。Demo 不接真实登录、权限、接口或持久化。

## Information Architecture

1. 剪辑供稿
2. 上传稿件
3. 第一步：项目选择（本 FR 不改）
4. 第二步：填写并选成片（本 FR 的书籍搜索、补空和下一步校验）
5. 第三步：最终提交（本 FR 不再次拦截）

第二步表面包含书籍名称、书籍 ID、书籍类型、书籍链接、成片素材选择和底部导航。书籍名称和 ID 各自拥有候选浮层；下一步校验以第一步项目映射的项目系决定。管理后台页为只读校验对照表，不提供规则配置。

## Voice and Tone

使用直接、可执行的中文。候选空态固定为「暂无结果」。辅助说明为「支持按书籍名称或书籍 ID 模糊搜索，点选只补空字段」。校验文案严格使用 PRD：字节系「书籍ID与书籍不匹配，确认要继续提交吗？」；知乎系「书籍链接与书籍名称不匹配，确认要继续提交吗？」；海外短剧/小说「书籍ID与书籍名称不匹配，请填写正确后再提交！」。

## Component Patterns

### 模糊检索与候选

- 在书籍名称或书籍 ID 输入时按实现择优触发检索（可防抖、回车或聚焦后输入）；Demo 需能输入后展示候选。
- 查询范围由第一步项目映射的项目系决定；最多展示 20 条。
- 候选行可用键盘上下移动，Enter 选择，Esc 关闭；鼠标点击整行也可选择。
- 无结果展示「暂无结果」，不展示假数据行；查询中使用输入框附近轻量加载提示，不遮盖页面。

### 点选补空

- 记录点击瞬间四个字段的值。
- 当前触发检索的字段（书籍名称或书籍 ID）直接更新为候选对应值，即使原值是部分输入或非空。
- 其他字段仅在当时为空时写入候选值；已有值保持原值。
- 选择后关闭候选面板并将焦点回到触发字段；四个字段继续可编辑，不显示锁定态。
- 手动改值后重新点下一步，按当前值重新校验。

### 下一步与校验

| 项目系 | 对照字段 | 不匹配行为 |
|---|---|---|
| 字节系 | `yx_fanqie_book_lists` 的书籍 ID | 弹窗；取消留在第二步，继续提交进入第三步 |
| 知乎系 | `novel_sections` 的书籍链接 | 弹窗；取消留在第二步，继续提交进入第三步 |
| 海外短剧 | `yx_story_task.book_id` | 弹窗；只有关闭，留在第二步 |
| 海外小说 | `yx_story_task.book_id` | 弹窗；只有关闭，留在第二步 |
| 其他项目 | 无 | 不做本 FR 书籍校验，直接进入第三步 |

点击下一步时先完成本 FR 校验；无异常直接进入第三步。查库失败与未匹配分开呈现：保留已填写内容，显示系统异常，关闭后留在第二步；海外项目不因查库失败拦截。百分百匹配比较前去掉首尾空格，仍不忽略 query、尾斜杠、http/https，不做大小写折叠。第三步最终提交不执行本 FR 拦截。

## State Patterns

- **初始：** 书籍字段可编辑，候选未打开。
- **输入中：** 当前字段保留输入值，候选面板展示匹配结果、加载、暂无结果或系统异常。
- **已点选：** 当前触发字段更新，其他字段只补空；候选面板关闭；焦点回到触发输入。
- **部分填写：** 当前触发检索字段允许被候选值覆盖；其他已有字段都视为用户内容，后续点选不得覆盖。
- **校验无异常：** 点击下一步后直接进入第三步。
- **国内项目系异常：** Modal 打开，取消恢复第二步原状态；继续提交进入第三步。
- **海外项目系异常：** Modal 打开，关闭恢复第二步；不提供继续按钮。
- **其他项目：** 跳过书籍校验，沿用原有其他校验。
- **键盘/动效：** Esc 关闭最上层候选或弹窗；遵循 `prefers-reduced-motion`。

## Interaction Primitives

- Tab 顺序按页面阅读顺序：项目上下文 → 书籍名称 → 书籍 ID → 类型 → 链接 → 成片素材选择 → 底部按钮。
- 候选面板使用 `aria-expanded`、`aria-controls` 和 `role=listbox/option`；当前候选有可见 focus。
- 弹窗打开时焦点进入标题或首个操作，关闭后回到下一步按钮；遮罩点击行为沿用现有 Modal 规范。
- 防止重复提交：下一步校验期间按钮进入 loading/disabled；恢复后根据结果导航或保留当前页。

## Accessibility Floor

输入框和按钮必须有可见 label/可访问名称；纯图标关闭按钮提供 `title`。焦点环使用 `{colors.primary}`；错误/警示文案不能只靠颜色表达。弹窗需支持键盘操作并将焦点限制在弹窗内。缩放到 200% 时不丢失字段、候选和按钮；小屏按 `DESIGN.md` 的响应式规则降级。

## Responsive & Platform

主目标为 PC 浏览器。宽度不足时表单从四列降为两列、一列；候选面板跟随输入框宽度。小屏沿用迭代外壳的侧栏收起、弹窗近全屏和横向安全边距，不改变校验规则和文案。

## Key Flows

### Flow 1 — 周然按书名选书并补空

1. 周然已在第一步选择番茄小说，进入第二步；书籍名称已有手头资料，ID、类型、链接为空。
2. 他在书籍名称输入关键词，看到候选列表，点选一行。
3. **高潮：** ID、类型、链接被补入，原书名保持不变；四个字段仍可编辑。
4. 他继续填写成片素材选择并点下一步；若 ID 百分百匹配，直接进入第三步。

### Flow 2 — 周然按 ID 搜索但保留已填名称

1. 周然先手填书籍名称，再在书籍 ID 输入片段。
2. 他点选候选；候选覆盖当前触发的书籍 ID，书籍名称等其他字段只在为空时补入。
3. 他修改链接后点下一步；系统按修改后的值重新判断。

### Flow 3 — 字节系不匹配仍继续

1. 周然选择红果短剧 APP，填写的书籍 ID 未在字节书库百分百匹配。
2. 点下一步，弹出「书籍ID与书籍不匹配，确认要继续提交吗？」。
3. **高潮：** 他点「继续提交」进入第三步；点「取消」则回到第二步且字段不变。

### Flow 4 — 海外项目阻断

1. 周然选择海外小说，书籍 ID 与名称不匹配。
2. 点下一步，弹出「书籍ID与书籍名称不匹配，请填写正确后再提交！」。
3. 他只能点「关闭」；弹窗关闭后仍在第二步，修正字段后再次点下一步。

## Confirmed Decisions

- 百分百匹配比较前去掉首尾空格；不忽略 query、尾斜杠、协议和大小写差异。
- 查库失败单独显示系统异常，海外项目不因故障拦截；关闭后回到第二步。
- 书籍类型与名称、ID、链接同表，点选后允许手改。
- 校验只发生在第二步点击下一步；第三步最终提交不拦截。
