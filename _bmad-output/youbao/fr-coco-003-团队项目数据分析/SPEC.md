# FR-CoCo-003 · 团队项目数据分析 · 实现规格

业务线：右豹主业务
需求真源：`references/team_project_member_data_mobile_h5_v4_2_with_requirements.html`
产品合同：`prd.md`；视觉与交互合同：`DESIGN.md`、`EXPERIENCE.md`

## 页面与路由

1. 团队数据页在既有「成员数据」白色卡片底部内嵌「项目数据」入口行，位于三项成员指标之后并以分隔线连接；不新增独立「项目分析」分区或外置入口卡。
2. 项目数据页依次展示累计与今日的奖励/流水合并概览、奖励/流水构成图、项目排行榜/成员排行榜双 Tab；顶部概览不展示昨日统计。
3. 项目详情展示项目身份、成员奖励排行/成员出单排行双 Tab，不展示旧版顶部 KPI。
4. 全项目成员点击打开汇总抽屉；单项目两榜点击均跳转既有「成员产生奖励详情页」，传成员 ID 与项目 ID。
5. 静态评审页支持 `?tab=fe|flow`，不新增管理后台产品页。

## 字段与交互

- 顶部统计使用一个双列组件，今日值为灰色辅助文字，奖励值不单独高亮；页头问号图标打开统计规则说明，内容由后台 `data.tips` 字段配置。
- 构成图支持项目奖励 / 项目流水指标下拉和累计 / 今日 / 昨日周期切换，按当前指标降序展示 Top 5，其余聚合为「更多项目」；列表排序不改变图表。
- 项目卡展示项目名称、Icon、累计/今日/昨日团队奖励与对应出单流水；排行榜仅提供累计/今日/昨日三种出单流水降序，Icon 缺失时使用兜底图。
- 全项目成员榜展示昵称、用户 ID、成员关系、有效出单量、出单流水、团队奖励；支持 ID/昵称搜索、五类关系、五种时间、三种降序，最多前 100 名。
- 项目详情两榜共用搜索、五类关系和五种时间，不提供排序下拉；奖励榜按团队奖励降序，出单榜按出单流水降序并突出有效出单量；每榜最多前 100 名。
- 全项目汇总抽屉使用列表所选周期，展示三项总计与各项目三项明细。

## 数据与权限

- 出单流水是有效订单交易金额，不是成员个人收益。
- 跨项目订单按订单唯一 ID 去重；成员关系与奖励归属是两个独立维度。
- 敏感订单量与出单流水须同时执行前端展示控制和后端账号、团队、项目范围校验。
- 搜索/筛选无结果显示空态；接口失败显示重试，不得将失败、缺失或无权限显示成 `0`。

## Demo 边界

- 使用已授权、非负、无并列且不含多项目关联订单的 Mock，不接真实接口、登录、权限或持久化。
- 单项目成员点击仅展示既有页面交接提示，不模拟新详情页。
- 固定项目名、成员名、金额、日期、关系分布和前端造数算法不构成生产合同。
