# 需求单

业务线：右豹主业务

需求名：代发上融合任务

全局编号：FR-003（PRD 正文中的 FR-1、FR-2 仅表示本需求内的条目编号）

照着哪条现有需求做：一键代发；报名复用现有开白表单功能

谁在用：剪辑手 PC 客户端供稿用户、参与星图融合任务的右豹用户、审核报名及账号资质的运营

从哪个入口进来：剪辑手沿用 PC 客户端供稿上传入口；创作者沿用一键代发广场，项目筛选新增融合短剧、融合漫剧、融合故事。无已报名抖音号时，点击领取稿件弹窗引导，通过「立即报名」进入现有报名表单；有已报名抖音号时，点击「立即领取」弹出选抖音号上拉弹窗，通过「其他抖音号报名」进入现有报名表单增加账号。

流程图补充：整体流程按“运营后台—剪辑手—创作者”三方泳道协作。运营后台涉及一键代发、项目管理、剪辑手管理、稿件管理及稿件上传记录；剪辑手从新建稿件、上传稿件开始，经历书籍/项目匹配、审核和上架；创作者完成任务报名、账号审核、抖音号选择、稿件领取、发布、回填和收益结算。流程图中的具体页面名称以现有系统为准。

接着怎么点：

1. 剪辑手在 PC 客户端上传融合任务稿件，填写或检索书籍名称、书籍 ID；两项需要能够从星图任务中正确匹配检索，匹配不正确时限制提交进入下一步。
2. 用户通过现有开白表单填写发布融合任务的抖音号报名信息，上传资质截图。
3. 报名审核完整沿用现有开白表单审核，不新增审核能力。运营人工审核截图，核实账号无违规、已实名且成年、已设置提现、总粉丝量大于等于 1000、有效粉丝量大于 500；审核通过后才可继续领取稿件流程。
4. 用户可同时拥有多个报名抖音号。审核通过且满足资质条件的抖音号可在后续星图融合任务中重复选择。
5. 用户领取融合任务稿件时，选择参加任务的抖音号进行任务关联；没有满足条件的抖音号则不能领取。融合任务关联抖音号；关键词要求按运营模式区分，账号运营分支见下述补充。
6. 用户按一键代发既有领取次数规则领取稿件并发布视频。
7. 用户进入回填，系统默认带出领取时选择的抖音号，且不可修改。
8. 用户填写视频链接，点击“确认回填”后，系统才解析账号信息和视频 ID。
9. 系统先校验解析账号与本次领取关联的报名抖音号是否一致。不一致时回填失败，弹窗提示“视频链接与报名抖音号不匹配”，让用户重新填写；不记录违规。
10. 账号校验通过后，校验解析的视频 ID 与接口拉回的视频 ID 是否一致。不一致时回填失败，提示用户重新填写，如有疑问可咨询客服。
11. 校验通过后完成回填，沿用一键代发分账规则；只有完成回填才形成有效分账绑定。
12. 未回填的时限、累计次数及停权处理沿用一键代发既有规则，不新增融合任务独立的未回填停权阈值。
13. 流程图显示，剪辑手稿件需经过书籍/项目匹配和审核后才进入一键代发稿件池；审核不通过时返回修改，审核通过后上架。
14. 创作者报名后先经过账号资质审核；审核未通过可返回修改报名信息，审核通过后进入抖音号选择和稿件领取。
15. 创作者发布后进入视频链接回填；回填成功后复用一键代发收益明细展示收益，不新增独立的“任务完成”节点。
16. 流程图中仅区分任务领取和回填流程；未完成回填的任务进入一键代发既有的超时、释放及停权处理。

后台要看什么：

- 复用现有开白报名审核和既有稿件、领取、回填及停权管理。其余原有字段展示范围见 PRD 的 `[ASSUMPTION]` 索引。
- 「稿件管理_稿件列表」沿用审核状态（待审核、已通过、已驳回）、稿件状态（正常、已删除），不新增独立上架状态字段。
- 「稿件管理_领取记录列表」新增「参与任务信息」列，展示该领取记录从抖音官方拉回的实际发布抖音号、视频 ID、视频 URL 链接；无法匹配对应内容显示「-」，供运营查看真实视频内容。
- 同一领取记录列表新增「涉嫌违规」列（是、否），展示一键代发稿件领取记录的违规；该列不恢复本次取消的官方任务数据比对记违规。数据来源、判定和更新沿用一键代发现有违规停权判定；每次领取都有一条记录，领取后未在 24 小时内回填，按既有规则记录违规，并在这条领取记录标记「是」，不影响同一用户的其他领取记录。
- 「稿件管理_稿件列表」的「回填数量」支持点击，弹窗逐条展示本稿件多个回填信息：创作者信息（用户昵称、用户 ID）；回填信息（投稿平台，如抖音/快手/小红书等、昵称、视频链接、视频 ID、发布日期、作品类型：图文/视频/其他、内容类型：例如漫剧/真人演绎/解压/解说）；参与任务信息（从抖音/合作项目官方拉回的平台名称、昵称、视频链接、视频 ID）。无法匹配官方内容显示「-」。

哪些情况不允许：

- PC 供稿书籍名称、书籍 ID 无法从星图任务中正确匹配检索，不允许提交进入下一步。
- 用户未报名、报名未通过运营审核，或没有已报名且满足资质条件的抖音号，不允许领取融合任务稿件。
- 抖音号有违规、未实名、未成年、未设置提现、总粉丝量小于 1000、有效粉丝量小于等于 500，或未上传资质截图，不满足报名资质。
- 回填时不允许修改领取时选择的抖音号。
- 解析账号与本次领取关联的报名抖音号不一致，或解析的视频 ID 与接口拉回的视频 ID 不一致，不允许完成本次回填。
- 账号不一致只提示重新填写，不计违规。
- 取消回填成功后再次拉回抖音官方任务数据比对回填信息并记录违规的处理，暂不记违规；不沿用本 FR 原先的累计三次违规停权条款。回填即时账号与视频 ID 校验保留，不一致阻断回填但不新增违规；其他一键代发既有停权条件不变。
- 达到一键代发既有停权条件，不允许继续领取。
- 稿件书籍/项目匹配或审核未通过，不允许进入稿件池供创作者领取。
- 报名账号资质审核未通过，不允许进入抖音号选择和稿件领取。

这次不做的：

- 不新建独立报名表单能力，复用现有开白表单及运营审核。
- 不为融合任务另设领取次数、分账或未回填停权规则。
- 不新建关键词流程。融合任务关联参加任务的抖音号；运营模式为账号运营时，按既有分支关联和领取关键词，不把关键词要求推广至所有融合任务。
- 本次更新需求单与 PRD，不在这一步制作设计或页面。

还没定的：

已确认的入口、项目筛选、状态枚举、后台新增展示和取消事后比对记违规规则已同步 PRD。[ASSUMPTION] 尚需核对报名审核以外其余既有后台字段展示范围，以及零条时表现、明细排序与分页、部分字段缺失等弹窗明细边界；涉嫌违规判定与回填数量统计口径已确认，详见 PRD 假设索引。

2026-10-22 补充确认：抖音官方接口拉回的视频 ID 可作为本次回填校验基准；接口失败沿用既有系统处理，不新增重试策略。

2026-10-22 本轮补充确认：

- 报名审核沿用现有开白表单审核，不做新增。
- 涉嫌违规来源、判定及更新沿用一键代发现有违规停权判定；领取后未在 24 小时内回填，在对应的该条领取记录标「是」。
- 回填数量指当前稿件被领取后形成的回填记录条数。剪辑手上传稿件选择「账号运营」时需关联关键词，支持多个关键词；创作者每次只能领取一个关键词，基于每个关键词的回填信息生成一条回填记录。同稿件多个关键词被领取并回填后形成多条记录；仅关联或领取而未回填不计为已回填记录。
