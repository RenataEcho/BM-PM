# PRD: 代发上融合任务

## 2026-10-22 二次评审：独立任务接取与稿件领取校验

此节为最新确认，覆盖此前将获取二维码与抖音号选择绑定的描述。

- **独立接取融合任务**：任务详情点击「获取二维码」直接生成当前用户专属任务二维码并标记当前融合任务已接取；后续可刷新二维码。不校验报名状态、不选择或绑定抖音号，不创建稿件领取记录。
- **领取稿件的校验顺序**：稿件详情点击「立即领取」先检查报名状态；未报名沿用报名提示和入口。已报名再检查当前稿件关联的融合任务是否已接取；未接取弹窗提示「您尚未接取当前稿件关联的融合任务，请先接取任务后再领取稿件。」，按钮「去接取任务」跳转融合任务详情。报名且已接取关联任务后，才选择本人合格抖音号并领取稿件。其他任务的已接取状态不能替代当前关联任务。
- **申请记录**：报名页底部左侧增加图标加「申请记录」入口，右侧保留提交报名。记录页提供全部、待审核、审核通过、已驳回筛选；卡片展示申请时间、审核状态、抖音昵称、抖音号、五项资质截图及已有审核意见。返回报名保留未提交的填写内容。Demo 提交生成本地待审核记录，不调用服务或持久化。
- **删除不合格抖音号**：选择领取抖音号浮层中，仅不合格账号右侧显示垃圾桶图标。点击弹出确认删除提示，取消保留原账号，确认后从本地可选账号列表移除；合格账号、待审核账号不显示此删除图标。删除不影响历史申请记录或已领取稿件关联信息。
- **演示边界**：二维码为不可用于真实扫码的本地示意；截图仅保留当前页面会话内的本地文件引用。复用现有组件样式与浮层，无真实接口、登录、权限或持久化。
- 业务流程：见本页业务流程。

## 0. Document Purpose

本文只覆盖全局迭代 **FR-003「代发上融合任务」**，业务线为右豹主业务（`youbao`）。它定义融合任务稿件供稿、抖音号报名与资质审核、稿件领取、视频回填和收益绑定的产品规则，供后续 `DESIGN.md`、`EXPERIENCE.md`、`SPEC.md` 与 Demo 使用。本文不并入其他迭代 PRD。

正文中的 **FR-1、FR-2…** 只表示本增量内的条目编号，不是全局编号；全局编号写在 front matter 的 `iteration_id: FR-003`。本需求目录输入为同目录 `需求单.md`。本需求 Demo 为 `demo/iteration/fr-003-fusion-task.html`，嵌入 `fr-003-fusion-mobile.html` 与 `fr-003-fusion-pc.html`，覆盖前端交互、管理后台与业务流程。

## 1. Vision

让剪辑手可以把融合任务稿件准确送入一键代发稿件池，让创作者用已通过资质审核的抖音号领取并发布稿件，再以领取时绑定的抖音号完成视频回填和收益结算。融合任务复用一键代发已有的领取次数、未回填时限、超时释放、停权和分账规则，只增加融合任务所需的任务匹配、抖音号资质和回填一致性校验。

成功的体验是：稿件先经过书籍/项目匹配和审核；创作者先完成报名与账号审核；融合任务领取时关联参加任务的抖音号；融合项目仅开放任务协作；回填时系统锁定该抖音号，并在确认后仅校验作品发布账号，校验通过才形成有效分账绑定。

## 2. Target User

### 2.1 Jobs To Be Done

- **剪辑手 PC 客户端供稿用户：** 上传融合任务稿件，填写书籍名称、书籍 ID、书籍类型、书籍链接，确认与星图任务正确匹配后提交审核。
- **参与星图融合任务的右豹用户：** 通过现有开白表单报名一个或多个抖音号，提交资质截图，审核通过后选择合格抖音号领取稿件、发布视频并回填链接。
- **运营：** 审核报名账号资质和稿件，查看多条回填明细、官方参与任务内容和领取记录涉嫌违规信息，并追踪既有停权状态。

### 2.2 Non-Users

- 不参与融合任务的普通右豹用户。
- 不负责稿件审核、报名审核或运营排查的其他角色。
- 需要新建独立报名表单、独立分账或独立停权规则的管理人员；本 FR 不提供这些能力。

### 2.3 Key User Journeys

**UJ-1：剪辑手上传并上架融合稿件**

剪辑手在 PC 客户端新建稿件，填写书籍名称、书籍 ID、书籍类型、书籍链接。系统必须能从星图任务正确匹配；匹配失败时阻止进入下一步。稿件经过书籍/项目匹配和运营审核后，审核通过才进入一键代发稿件池；不通过则返回修改。

**UJ-2：创作者报名多个抖音号并复用资格**

创作者使用现有开白表单提交抖音号报名信息和资质截图。运营人工核验账号无违规、已实名且成年、已设置提现、总粉丝量不少于 1000、有效粉丝量大于 500。一个创作者可以有多个报名抖音号；每个通过审核且满足资质的抖音号可在后续融合任务中重复选择。审核不通过时可返回修改报名信息。

## 3. Glossary

- **融合任务**：星图中的任务类型；本 FR 的稿件、报名、领取和回填均围绕该任务。
- **星图任务**：用于匹配剪辑手填写的书籍名称、书籍 ID 的任务来源。
- **剪辑手**：在 PC 客户端新建并上传融合任务稿件的供稿用户。 
- **创作者**：报名抖音号、领取稿件、发布视频并回填视频链接的右豹用户。
- **报名抖音号**：创作者通过现有开白表单提交并接受资质审核的抖音号。
- **合格抖音号**：报名审核通过，且满足本 FR 账号资质条件的报名抖音号。
- **稿件池**：审核通过并上架、可被创作者领取的一键代发稿件集合。
- **任务领取**：创作者选择合格抖音号并领取融合任务稿件的动作。
- **关联抖音号**：领取时选定、后续回填不可修改的报名抖音号。
- **视频回填**：创作者提交视频链接并完成账号、视频 ID 校验的动作。
- **解析账号**：系统从创作者确认回填的视频链接解析出的账号。
- **解析视频 ID**：系统从视频链接解析出的视频 ID。
- **接口视频 ID**：系统从抖音官方接口拉回、作为本次回填校验基准的任务视频 ID。
- **实际参与信息**：官方拉回的实际任务发布内容，用于运营查看，与创作者手工回填信息分别展示。
- **涉嫌违规**：领取记录展示列，取值为「是 / 否」；数据来源、判定和更新沿用一键代发现有违规停权规则。例如领取后未在 24 小时内回填，则该条领取记录标为「是」。不因官方内容未匹配或即时校验不一致直接记违规；持续未完成回填达到既有超时条件时仍按既有规则处理。
- **任务协作**：本需求融合类项目唯一开放的运营模式。
- **有效分账绑定**：视频回填校验成功后，按一键代发分账规则建立的收益关联。
- **一键代发既有规则**：现有一键代发的领取次数、未回填时限、累计次数、超时释放、违规与停权、分账及收益明细规则。

## 4. Features

### 4.1 融合任务稿件供稿与审核

#### FR-1：书籍/项目匹配后才可提交

剪辑手在 PC 客户端上传融合任务稿件时，必须填写书籍名称、书籍 ID、书籍类型、书籍链接，并与星图任务正确匹配。

**Consequences（可验收）：**

- 点击下一步时使用书籍名称和书籍 ID 匹配星图任务，不新增检索操作或状态行。
- 无法正确匹配时，提交按钮不能进入下一步，并明确提示需要修正匹配信息。
- 匹配成功后，稿件才能进入后续审核。
- 剪辑手入口沿用 PC 客户端供稿上传入口。

#### FR-2：稿件审核通过后上架

稿件经书籍/项目匹配后进入运营审核；审核不通过返回剪辑手修改，审核通过后上架到一键代发稿件池。

**Consequences（可验收）：**

- 审核不通过的稿件不能出现在创作者可领取的稿件池中。
- 审核不通过结果能回到剪辑手修改并重新提交。
- 审核通过的稿件才进入可领取状态。
- 运营后台「稿件管理_稿件列表」沿用现有字段：审核状态为「待审核 / 已通过 / 已驳回」，稿件状态为「正常 / 已删除」。不新增独立上架状态字段；原有上架流程沿用现有规则，稿件状态「正常」不等同于审核已通过。

### 4.2 报名抖音号与资质审核

#### FR-3：复用开白表单报名

创作者通过现有开白表单填写融合任务抖音号报名信息并上传资质截图；本 FR 复用现有开白表单及其审核，不新增表单或审核能力。

**Consequences（可验收）：**

- 创作者入口沿用「一键代发广场」页面，项目筛选新增「融合短剧」「融合漫剧」「融合故事」，可筛选对应项目稿件。
- 用户没有已报名抖音号时，点击领取稿件，弹窗引导报名；点击「立即报名」进入现有报名表单。
- 用户已有已报名抖音号时，点击「立即领取」，弹出选择抖音号的上拉弹窗；弹窗提供「其他抖音号报名」按钮，点击后进入现有报名表单，增加其他抖音号报名。
- 已报名不等于审核通过；上拉弹窗中的选择与领取仍受 FR-4、FR-5 的资质约束，没有合格抖音号不能领取。
- 报名记录至少保存报名抖音号、资质截图和报名审核状态。
- 运营能查看截图并记录人工审核结果。
- 审核不通过时，创作者可以返回修改报名信息并再次提交。

#### FR-4：按账号资质决定是否合格

运营只有在确认账号无违规、已实名且成年、已设置提现、总粉丝量大于等于 1000、有效粉丝量大于 500，且已上传资质截图后，才能将报名抖音号审核通过。

**Consequences（可验收）：**

- 任一条件不满足时，账号不能成为合格抖音号。
- 审核通过记录可用于后续融合任务的抖音号选择。
- 一个创作者可同时拥有多个报名抖音号。
- 每个合格抖音号可在后续融合任务中重复选择，无需重复报名，除非现有审核规则使其失效。
- 报名审核完整沿用现有开白表单的审核能力，状态、人工审核结果和资质截图展示沿用现有页面，不新增审核页面、流程或字段。

### 4.3 任务领取与抖音号关联

#### FR-5：只允许合格抖音号领取

创作者领取融合任务稿件时，必须从自己的合格抖音号中选择一个进行任务关联。

**Consequences（可验收）：**

- 未报名、报名未通过、资质不满足或没有合格抖音号时，不能领取稿件。
- 领取成功后保存本次领取关联的抖音号。
- 融合任务使用任务协作，以领取稿件时选择的抖音号关联；接取任务进入任务详情，获取专属二维码即接取成功。
- 领取次数沿用一键代发既有规则，不新增融合任务独立次数。

#### FR-6：回填默认使用领取关联账号

进入回填时，系统默认带出领取时关联的抖音号，创作者不能修改。

**Consequences（可验收）：**

- 回填页面展示关联抖音号。
- 关联抖音号为只读，不能切换为创作者的其他报名抖音号。
- 关联抖音号保存到领取记录和回填记录中。

### 4.4 视频回填校验与分账

#### FR-7：确认回填后才解析链接

创作者填写视频链接后点击「确认回填」，系统才解析账号和视频 ID。

**Consequences（可验收）：**

- 输入或编辑链接过程中不提前形成有效回填或分账绑定。
- 点击「确认回填」后记录回填视频链接，并启动账号和视频 ID 解析。
- 解析失败时不能完成回填，创作者可重新填写。

#### FR-8：校验解析账号与领取关联抖音号

仅在确认回填时比较作品发布抖音号和领取稿件选择的抖音号。

- 不一致时阻止回填，保留输入，不新增违规；标题「提交失败」。
- 正文「作品关联抖音号与领取稿件选择的抖音号不一致，请使用领取稿件选择的抖音号参与任务发布作品。」
- 一致时完成回填，不进行同步视频 ID 校验。

#### FR-9：后台定时获取实际参与信息

运营后台通过定时任务拉取抖音任务数据，与回填提交分离。

- 视频 ID、实际发布账号及链接用于后台核对，不作为回填提交时的同步阻断条件。
- 未匹配到官方信息显示「-」，不串用手工回填数据，不直接增加违规。

#### FR-10：成功回填形成有效分账绑定

仅作品发布抖音号与领取关联账号一致后，才完成回填并沿用一键代发分账规则。

**Consequences（可验收）：**

- 未完成回填的领取记录不能形成有效分账绑定。
- 回填成功后，收益明细复用一键代发展示和分账口径，不新增独立「任务完成」节点。
- 未回填时限、累计次数、超时释放和停权处理全部沿用一键代发既有规则。
- 不新增融合任务独立的未回填停权阈值。

### 4.5 后台可追踪信息

#### FR-11：在既有后台呈现融合任务状态

运营可以在现有报名审核、稿件、领取、回填及停权管理中追踪本 FR 所需信息。

**Consequences（可验收）：**

- 报名审核可查看报名抖音号、资质截图、人工审核结果和报名审核状态。
- 稿件管理可追踪 PC 供稿书籍名称、书籍 ID、对应星图任务和匹配结果；「稿件管理_稿件列表」复用审核状态（待审核、已通过、已驳回）和稿件状态（正常、已删除）。其他既有字段的展示范围见 A-1。
- 领取记录可查看领取关联抖音号、领取次数和任务领取状态。
- 回填记录可查看视频链接、解析账号、解析视频 ID、接口视频 ID、校验结果和回填状态。
- 既有停权管理可查看未回填次数、违规累计和停权状态。
- 新增列及回填明细按 FR-12 至 FR-15 执行；其余未定展示范围见 A-1。本 FR 不新增独立后台模块。

#### FR-12：领取记录新增「实际参与信息」列

「稿件管理_领取记录列表」新增「实际参与信息」列，用于查看该条领取记录从抖音官方拉回的实际参与任务发布内容。

**Consequences（可验收）：**

- 信息按本条稿件领取记录对应，包含实际发布的抖音号、视频 ID、视频 URL 链接，不以创作者手工回填信息冒充官方数据。
- 运营可通过视频 URL 链接查看真实发布内容。
- 无法匹配到对应内容时显示字符「-」，不展示其他领取记录的数据。
- 拉回的信息用于运营查看，不自动产生本 FR 已取消的事后比对违规记录。

#### FR-13：领取记录新增「涉嫌违规」列

「稿件管理_领取记录列表」新增「涉嫌违规」列，取值为「是 / 否」，用于展示一键代发稿件领取记录的违规信息。

**Consequences（可验收）：**

- 每条领取记录显示「是」或「否」，对应本条一键代发领取记录的涉嫌违规结果。
- 本列是展示能力；不因新增本列而恢复本 FR 已取消的官方任务数据比对记违规机制。
- 数据来源、判定和状态更新沿用一键代发现有违规停权判定，不新增独立规则。
- 每次领取稿件都生成一条领取记录；创作者领取后未在 24 小时内回填，按既有规则记录违规，并将该次领取记录的「涉嫌违规」标为「是」。未命中既有违规条件的记录显示「否」。
- 标记按具体领取记录展示，不因同一创作者某条领取违规而把其其他领取记录一并标为「是」。
- 官方内容未匹配或回填即时校验失败不直接产生违规；若因此持续未完成回填并达到既有超时条件，仍按既有规则记录该条领取违规。
- 后续状态更新与停权继续沿用现有机制，不另设累计阈值或自动清除规则。

#### FR-14：点击「回填数量」查看多条回填明细

「稿件管理_稿件列表」的「回填数量」指当前稿件被领取后形成的回填记录条数，支持点击，弹窗展示该稿件的多条回填信息。每条信息按下列三组展示，保留创作者回填内容与官方参与任务内容的区分。

**Consequences（可验收）：**

| 信息分组 | 每条明细字段 |
|---|---|
| 创作者信息 | 用户昵称、用户 ID |
| 回填信息 | 投稿平台（抖音 / 快手 / 小红书等）、昵称、视频链接、视频 ID、发布日期、作品类型（图文 / 视频 / 其他）、内容类型（例如漫剧 / 真人演绎 / 解压 / 解说） |
| 实际参与信息 | 从抖音 / 合作项目官方拉回的平台名称、昵称、视频链接、视频 ID |

- 弹窗只展示当前稿件的回填明细；同稿件存在多条回填时逐条展示，不只展示一条，也不混入其他稿件。
- 每条明细中的创作者信息、回填信息和实际参与信息保持对应关系，运营可点击视频链接查看内容。
- 实际参与信息来源于官方，不用手工回填值替代；无法匹配对应官方内容时显示「-」。
- 关键词仅被关联或领取但尚未回填时，不凭空生成已回填记录或增加回填数量。
- `[ASSUMPTION]` 零条时的弹窗表现、明细排序与分页，以及部分字段缺失时的展示方式尚未补充，待核对现有能力；回填数量的统计对象已确认。


#### FR-15：融合项目限定任务协作

融合短剧、融合漫剧、融合故事隐藏账号运营选项，沿用任务协作。账号运营及其关键词分支属于其他既有流程，本需求不重复演示。

## 5. Non-Goals（非目标）

- 不新建独立报名表单，复用现有开白表单及运营审核。
- 不为融合任务另设领取次数、分账、未回填时限、累计次数、超时释放或停权规则。
- 不新建关键词流程；账号运营沿用既有多关键词关联、单次单关键词领取及按关键词回填分支，不要求所有融合任务统一选择关键词。
- 不新增独立「任务完成」节点；回填成功后复用一键代发收益明细。
- 不改一键代发既有领取、收益、违规和停权规则的通用口径。
- 后续 Demo 不接真实接口、登录、权限和持久化，使用示例数据；此限制仅针对 Demo，不取消产品所需的官方数据拉取。
- 不把运营后台流程重做成新的项目管理、剪辑手管理、稿件管理系统。
- 不定义现有系统未确认的具体页面名、表名、字段展示位置或入口像素级布局。
- 不把导师商务、企业号或其他 FR 并入本文。

## 6. Success Metrics

这是内部流程增量，指标用于验收，不作为增长实验。

- **SM-1：** 书籍/项目匹配失败的稿件 0 次进入审核或稿件池。
- **SM-2：** 未通过账号资质审核或没有合格抖音号的创作者 0 次成功领取融合任务稿件。
- **SM-3：** 回填账号不一致时 100% 阻断回填且 0 次计入违规。
- **SM-5：** 仅作品发布抖音号与领取关联账号一致的记录才形成有效分账绑定。
- **SM-6：** 领取超过 24 小时未回填时，对应领取记录按既有规则标记涉嫌违规为「是」；领取记录可查看「实际参与信息」「涉嫌违规」；点击稿件「回填数量」可查看该稿件多条回填信息，官方内容无法匹配时显示「-」。
- **Counter-metrics：** 不得为了提高领取量而绕过账号资质审核、取消回填账号锁定或放宽视频 ID 校验；不得为了降低违规而把账号不一致误记为违规。

## 7. Assumptions & Open Questions

### 7.1 `[ASSUMPTION]` 索引

- **A-1 其余后台字段范围：** 报名审核完整沿用现有开白表单审核，不新增；稿件列表状态字段、领取记录新增列和「回填数量」弹窗已确认。领取关联信息、回填校验信息及停权管理中其余既有字段的具体展示范围仍需核对，不据此新增模块。
- **A-2 涉嫌违规数据口径（已确认，关闭）：** 来源、判定和更新沿用一键代发现有违规停权判定；领取后未在 24 小时内回填，则在该次领取记录标「是」。不恢复官方任务数据比对记违规。
- **A-3 回填明细边界（部分关闭）：** 回填数量为本稿件领取后的回填记录条数，按每次已完成回填的领取形成记录。仅零条时表现、明细排序与分页、部分字段缺失时展示方式仍待核对既有规则；官方内容无法匹配显示「-」已确认。

### 7.2 已确认口径

- 报名审核完整沿用现有开白表单审核，不新增。
- 「涉嫌违规」按领取记录沿用现有违规停权判定，领取后未在 24 小时内回填标「是」。

- 剪辑手沿用 PC 客户端供稿上传入口；创作者沿用一键代发广场，项目筛选新增融合短剧、融合漫剧、融合故事。
- 无已报名抖音号时，领取稿件弹窗通过「立即报名」进入表单；有已报名抖音号时，「立即领取」打开选抖音号上拉弹窗，通过「其他抖音号报名」新增报名。
- 稿件列表沿用审核状态（待审核、已通过、已驳回）和稿件状态（正常、已删除）。
- 账号资质条件：无违规、已实名且成年、已设置提现、总粉丝量大于等于 1000、有效粉丝量大于 500，并上传资质截图。
- 抖音官方接口拉回的视频 ID 可作为本次回填视频 ID 的校验基准；接口失败沿用既有系统处理，不新增重试策略。
- 领取和回填只区分任务领取、视频回填两段；未回填进入一键代发既有超时、释放和停权处理。
- 报名通过且满足资质的抖音号可复用；回填不可修改领取时选择的抖音号。

## 8. Scope Summary
