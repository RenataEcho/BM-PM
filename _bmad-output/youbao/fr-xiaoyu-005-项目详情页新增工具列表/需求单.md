# 项目详情页新增工具列表

本需求以用户最新提供的内容为准，重新记录，不继承已取消草稿中的额外规则。用户已授权上传 GitHub；编号 FR-XIAOYU-005。上传目标与重号处理待确认。

## 后台配置

工具后台新增字段“展示项目”，下拉框支持多选线上所有项目。

- 工具仅在“展示项目”已勾选的对应项目详情页展示。
- 未勾选任何展示项目时，该工具不在任何项目详情页展示。

## 前端展示

- 未登录情况下正常显示。
- 根据工具配置，在对应项目详情页展示工具名称和标签。
- 标签来源于工具配置，由后台动态返回，支持最多展示 3 个标签。
- 命中工具数量 > 5：推荐工具模块右上角展示“更多”按钮。
- 命中工具数量 ≤ 5：不展示“更多”按钮。

## 点击判断顺序

### 1. 优先判断使用端口

- 当前访问端不在工具配置的“使用端口”范围内：点击提示“请前往 {端口名称} 使用”，结束判断。
- 当前访问端在配置范围内：继续判断“使用门槛”。
- 使用端口支持后台多选；提示中的端口名称按工具配置动态展示，可包含多个端口。

### 2. 判断使用门槛

- 完全免费：直接跳转工具页。
- 积分使用，当前用户积分 ≥ 工具所需积分：直接跳转工具页，包括积分恰好相等的情况。
- 积分使用，当前用户积分 < 工具所需积分：弹出积分不足提示。

## 积分不足弹窗

- 文案：该工具所需积分xx，您当前积分不足，是否前往积分兑换？
- xx 为当前工具所需积分。
- 按钮：取消 / 前往兑换。
- 取消关闭弹窗，前往兑换进入积分兑换页面。

## 验收要点

| 场景 | 预期 |
| --- | --- |
| 工具未勾选任何展示项目 | 不在任何项目详情页展示 |
| 工具仅勾选项目 A | 在 A 详情页展示，在未勾选项目不展示 |
| 未登录查看项目详情 | 正常展示匹配工具 |
| 后台返回 1、2、3 个标签 | 展示对应标签，不使用前端固定分类文案 |
| 命中 5 个工具 | 不展示更多 |
| 命中 6 个工具 | 展示更多 |
| 当前端不在使用端口范围且积分不足 | 仅提示可用端口，不弹积分不足提示 |
| 当前端匹配且完全免费 | 直接进入工具页 |
| 工具需 10 积分，用户有 9 积分 | 弹出积分不足提示 |
| 工具需 10 积分，用户有 10 或 11 积分 | 直接进入工具页 |

以下未在本版明确，不沿用已取消草稿的规则：

3. 返回超过 3 个标签时的选择和排序规则。

5. 多端名称的展示顺序、分隔方式及没有配置使用端口时的提示。
6. 弹窗是否支持点击蒙层关闭。
