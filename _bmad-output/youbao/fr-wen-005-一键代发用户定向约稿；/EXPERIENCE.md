# FR-wen-005 · 行为合同 · ux-v3

## 主旅程

已领—已回填 → 查看原稿收益 → 约稿 → 只读确认来源信息、填写说明 → 提交 → 原卡片变约稿详情 → 剪辑手通过 → 制作及右豹上传 → 后台现有审核 → 待领取通知 → 关联约稿详情 → 稿件详情 → 免费领取 → 约稿申请结束为已领取稿件；已领新增未回填 → 下载、发布及24小时内回填。

## 来源与关联

每个申请绑定 sourceClaimId，关联查询按领取记录ID，不按书名或关键词聚合。仅本人已回填可发起。提交时由来源重新赋值继承字段，客户端只读不能替代服务校验。说明选填；项目、关键词、书籍名称／ID／链接、剪辑手不可更换。原字段缺失显示未提供，不新增补录流程。可重复申请，每次独立记录；已拒绝／已撤销重新申请仍绑定原来源。

## 列表与返回

未回填、已超时不显示约稿操作；已回填显示用户原稿收益。尚无申请显示约稿，有申请后显示约稿详情，直接进入本原稿最近一次申请（按申请时间倒序）；全部较早申请仍可通过底部约稿菜单查阅。底部约稿展示本人所有来源的申请，状态筛选作用于全部本人申请。列表点约稿详情后进入独立详情页，完整显示状态、申请时间、编号、项目、关键词、书籍名／ID／链接、剪辑手及说明，无需再展开。待审核显示撤销；待领取、已领取稿件显示查看稿件详情。详情返回原列表或已回填卡片，稿件详情返回该申请详情；已领回填页返回已领。通知直达对应申请详情。

## 审核与上传

待审核可撤销或由剪辑手通过／拒绝；通过与撤销先成功者生效，状态变化后不能重复操作。拒绝原因必填；接受后用户不可取消。审核列表关键词继承原稿，已获取收益为剪辑手在原稿的收益。

供稿沿用三步，单申请单稿。项目、书籍、关键词、定向用户锁定，发布平台右豹。现有项目权限不满足阻止上传并提示联系客服，恢复后可继续；不增加平台权限配置。上传失败／取消留在制作中，不产生供稿记录；可重试。成功才写右豹稿件记录并进入稿件审核中，不发上传通知。驳回后修改同一稿件并重送审，保持稿件ID。通过审核后待领取，仅申请用户可领。

## 免费领取与记录分离

保留原详情及下载流程，移除快捷提词、选词和先领后填。关键词不从领取请求取值，直接继承来源。领取必须审核已通过、可领取、为申请人且未领过。成功仅新增一条未回填记录；旧已回填记录不变。新领取时间、24小时回填截止重新计算，发布URL及回填时间为空，收益及回填数量从零起。重复领取阻止新增。领取同时将约稿申请固定为已领取稿件终态。新记录回填只更新新稿件及新领取记录，不改变申请终态。

## 时间、通知与异常

不设交付或领取限制，无对应倒计时、超时状态、自动删除或 D+2 分支。领取后的已领记录仍按正常24小时回填，恰到截止仅该领取记录变为超时未回填；申请始终为已领取稿件。已领稿件保留，下载限制沿用现有规则。

只发两个节点通知：申请通过、稿件审核通过待领取。拒绝原因仅在记录内；上传审核中无通知。重复审核不重复通知。通知仅对申请人可见。

空态无主动申请按钮，提示从已回填发起；加载只替换内容区，错误提供重试，不伪装空数据。申请说明保留在表单状态，模型刷新不清空草稿。弹层沿用现有遮罩、确认、ESC关闭与焦点返回；无真实上传、下载、持久化或接口。

## 验收

逐项以 PRD 验收重点和16条批注追踪表对照。保留卡片／详情／上传结构是本轮验收要求。收益更新时间沿用现有结算数据源的假设见 PRD。

## 后台布局顺序

标题、稿件列表／领取记录／结算明细、筛选区、说明、右豹／站外／企业号稿件平台栏、稿件表格、分页。平台栏仅移动展示位置，不改变右豹供稿与审核规则。
