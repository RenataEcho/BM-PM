# FR-wen-004 · 一键代发_报名领取稿件。 · v7 当前

业务线：右豹主业务（youbao）

## 0. Document Purpose（文档目的）

本文件仅覆盖 FR-wen-004：后台按素材类型设置统一领取要求，剪辑手按稿件选择是否使用；创作者添加媒体账号，保存主页链接解析出的数据，领取时选择满足要求的账号；后台回填明细展示领取关联账号。

全局编号为 `iteration_id: FR-wen-004`；正文 FR-n 仅表示本增量内部功能编号。本版沿用 v4 对 v3 的调整，替换原有 的报名自动审核及每日数据更新方案：添加账号只解析并保存，不做领取要求审核；资格仅在领取时校验，后续使用添加时记录的数据，不再抓取更新。仍不建立创作者与剪辑手的合作关系。

输入为同目录需求单、产品历轮 B-1 至 B-9、C-1 至 C-7 补充及上传稿件截图。截图中「项目与投向」步骤的「素材类型」已标必填，与产品说明一致；仅作为现有界面参考，不从截图新增其他业务范围。后台参考 FR-003 最新领取记录及回填数量弹窗，不引入其回填账号一致性校验。当前已有 DESIGN.md、EXPERIENCE.md 和 demo/iteration/fr-wen-004-claim.html；本轮同步产品十项确认，仅更新文档，既有 Demo 后续按合同核对。

## 1. Vision（愿景）

让创作者在有领取要求的领取场景中添加多个媒体账号，领取稿件时直接从账号列表选择满足目标素材类型要求的账号。账号无需按素材类型重复报名审核，也不与剪辑手建立长期合作资格。

平台通过粉丝量、关注数、获赞数统一管理领取门槛。账号数据固定为添加时的解析记录，系统按当前素材类型规则判断账号是否可选；规则不满足则在选择时说明原因，不阻止该账号保存到用户账号列表。

## 2. Target User（目标用户）

### 2.1 JTBD

| 用户 | 任务 | 结果 |
|---|---|---|
| 后台人员 | 按素材类型设置门槛，查看领取与回填信息 | 统一准入规则并追溯本次领取关联账号 |
| 剪辑手 | 上传稿件，必选素材类型并选择是否使用统一要求 | 本稿件按确定配置提供领取 |
| 创作者 | 添加、删除媒体账号，选择满足要求的账号领取并回填 | 不等待审核，使用已保存账号数据完成领取判断 |

### 2.2 Non-Users（本期非目标用户）

本期不支持抖音、快手、小红书、视频号以外的平台账号；不支持剪辑手自定义指标阈值或人工审核用户。

### 2.3 UJ（关键用户旅程）

- **UJ-1：配置与供稿。** 后台在「素材类型」配置启用指标、比较符及阈值；剪辑手第一步沿用原流程选择素材类型，第二步仅有规则时逐书籍卡片选择是否使用，无规则隐藏；每卡片打包一个稿件，成功后不能更改配置。
- **UJ-2：添加账号。** 创作者领取有要求的稿件，若账号列表为空，收到添加账号提示；选择平台、填写主页链接，系统解析资料、展示并保存到本人账号列表，不审核是否满足稿件要求。创作者可新增多个账号，也可删除账号。
- **UJ-3：选择账号领取。** 创作者已有账号，系统用账号记录的数据匹配目标素材类型当前要求。不满足的账号禁止选择并提示原因；没有任何满足项时提示添加满足要求的账号；有满足项时选择一个并领取。
- **UJ-4：回填与后台查看。** 创作者回填时不校验作品账号与领取关联账号一致性。后台进入「稿件管理－领取记录」，点击本条领取的「回填数量」，在弹窗中查看该次领取的关联账号及回填内容。

## 4. Features（功能需求）

### 4.1 后台统一要求

#### FR-1：按素材类型配置领取要求

后台人员在「素材类型」设置领取要求，实现 UJ-1。

**Consequences（可验收结果）：**

- 粉丝量、关注数、获赞数各自支持是否参与限制；新建素材类型时三项均默认「不限制」，未启用项不参与判断。
- 每个启用项配置 ≤ 或 ≥ 和非负数阈值，阈值可为 0，不将 0 当成未填写；不把阈值限定为必须大于零的整数。
- 启用项条件填写完整后才可保存；负数、缺失比较符或缺失阈值不可保存。
- 多项启用取逻辑“且”，边界包含等号；任一项不满足即不能使用该账号领取。
- 三项全部关闭时，无需添加或选择账号，可直接领取；不因稿件选择使用统一要求而额外要求账号报备。
- 不同素材类型分别配置，不混用规则。素材类型沿用居中新增/编辑弹窗，列表无需详情查看操作，删除先确认。

#### FR-2：规则变更与失败说明

系统在后续领取中使用当前适用规则，实现 UJ-3。

**Consequences（可验收结果）：**

- 后台保存变更后，后续领取按最新规则校验；已完成领取的历史记录不追溯撤销，不覆盖其关联账号记录。
- 不存在需要随规则变更处理的报名审核状态，规则变化不改变账号保存事实。
- 向创作者展示当前启用指标的比较符与阈值。
- 账号不满足多个条件时，一次展示全部失败项、记录值及对应要求，不只提示“失败”。
- 示例：粉丝量 ≥ 1000，账号记录为 999 时不满足，1000 时满足；粉丝量 ≤ 0 时，记录为 0 满足。示例不是默认规则。

### 4.2 剪辑手上传配置

#### FR-3：必选素材类型并选择是否使用要求

剪辑手按稿件选择是否使用平台统一领取要求，实现 UJ-1。

**Consequences（可验收结果）：**

- 上传第一步完全沿用现有流程，素材类型必填属既有规则，本需求不改第一步。第二步依据其所选类型决定是否显示领取规则配置。
- 所选类型至少启用一项领取规则时，第二步每本书卡片显示「领取稿件限制：不限制 / 使用平台统一限制」，默认不限制；三项全关时隐藏整组配置并按不使用处理，不保留隐藏的使用值。返回第一步更换类型后，按新类型更新第二步显示。
- 每本书卡片仅一组设置，同卡片多条内容上传后打包为一个稿件，整体采用此配置；不设逐内容不同开关。第三步只读核对，修改回第二步；不允许剪辑手自定义阈值。
- 稿件上传后不可更改配置内容，包括素材类型和是否使用统一要求。
- 不使用时，不因本需求增加账号或指标限制，其他现有领取规则继续适用。
- 使用时取该素材类型当前统一规则；剪辑手上传后配置不可改，不妨碍平台后台修改统一规则后对后续领取生效。
- 三项全关与不使用统一要求均走无领取要求路径，不强制选择账号。

### 4.3 添加并保存媒体账号

#### FR-4：解析链接并保存账号，不进行报名审核

创作者添加媒体账号，实现 UJ-2。

**Consequences（可验收结果）：**

- 平台选项仅为抖音、快手、小红书、视频号；填写发布平台及账号主页链接。
- 系统通过主页链接识别账号昵称、账号 ID、粉丝量、关注数、获赞数，展示识别结果并保存到本人账号列表。
- 添加时不与任何素材类型要求比较，不产生待审核、审核通过或自动驳回状态，不发送报名审核结果消息。
- 即使指标不满足当前稿件要求，解析成功的账号仍可保存；能否领取由 FR-6 判断。
- 链接无效或解析失败时提示更正或重新尝试，不伪造成功数据，不用 0 代替缺失指标；真实识别出的 0 为有效值。
- 账号身份和粉丝量、关注数、获赞数三项指标均成功识别后才允许保存；任一必需信息缺失不可保存，不因目标素材类型未启用某指标而省略该指标解析。
- 账号保存后，后续领取均按该账号记录中的三项指标判断，不每日抓取、不自动刷新，也不在领取时重新解析。

#### FR-5：支持多账号与删除

创作者仅在有领取要求的领取账号选择弹窗内选择、删除本人账号，不设独立管理页或入口，实现 UJ-2。

**Consequences（可验收结果）：**

- 同一右豹用户可添加多个媒体账号，账号数量暂不设上限；逐个添加，不增加批量导入。
- 同一社交媒体账号可归属多个右豹用户，暂不限制；每位用户只能从本人保存的账号记录中选择，不直接展示其他用户列表。
- 选择弹窗提供添加与删除，删除须另弹二次确认；取消不改变原列表和选择。成功删除后移除该项，若为已选账号则清空选择；删至空列表时提示添加。删除失败保留原项并允许重试。
- 同一右豹用户重复添加相同平台和账号 ID 时去重，不新增重复账号记录；已保存账号不支持编辑。跨右豹用户仍可分别保存同一媒体账号。
- 删除后重新添加相同平台和账号 ID 时，重新解析并生成新账号记录；身份和三项指标均成功识别后保存。新记录不覆盖原历史领取关联信息，已保存且未删除的账号仍去重、不支持编辑或刷新。
- 删除只移除本人可选列表项，保留历史领取关联信息；不得因另一用户保存同账号而联动删除，也不修改既有领取事实。
- 账号添加表单可复用已有开白表单的账号字段，但不得沿用其审核流程；已有页面仍需在设计前补齐。

### 4.4 领取与回填

#### FR-6：按已保存的数据筛选并选择领取账号

创作者领取有要求的稿件时，检查本人账号列表并选择合格账号，实现 UJ-3。

**Consequences（可验收结果）：**

| 稿件与列表状态 | 处理 |
|---|---|
| 不使用统一要求，或素材类型三项全关 | 无需账号报备或选择，按现有规则直接领取 |
| 有领取要求，账号列表为空 | 点击领取后直接弹窗提示去添加媒体账号，不先展示空选择列表，不能跳过要求 |
| 有领取要求，已有账号 | 打开详情页底部选择弹窗，合格项可单选，记录一个关联账号后领取 |
| 有领取要求，部分账号不满足 | 不满足项禁止选择，展示全部不满足原因，满足项仍可选 |
| 有领取要求，全部账号不满足 | 提示添加满足领取要求的账号，不允许用不满足项领取 |

- 点击有要求稿件的领取按钮先读取本人账号；读取失败提示重试，不当成空列表。已有账号则打开底部选择弹窗，无账号直接弹添加提示；添加按「识别账号 / 保存账号」两步，保存后返回选择弹窗重新判断并清空选择，不自动领取。
- 已选账号并发失效且无法关联时提示返回重选，不伪造成功，不追加指标或规则重审。
- 校验对象为账号记录保存的指标，不使用实时社交媒体数据，不因账号添加时间较早而自动刷新。
- 账号列表全平台复用，按本次目标稿件素材类型规则判断，不因曾符合另一个类型而免检。
- 发布平台不限制可选账号范围：本人已保存的四个平台账号均可按三项指标判断是否可选，不因稿件发布平台与账号平台不同而排除。此规则不扩展账号添加的四个平台范围。
- 在进入领取账号列表时，使用已存数据与当时的素材类型规则判断账号可选性；领取提交时不再次使用已存数据和当前规则校验。若后台规则在选择后、提交前变化，本次不因规则变化追加重复校验；后续新进入的领取按最新规则判断。此规则不取消其他现有领取校验。
- 不建立剪辑手合作关系，不因另一个右豹用户使用相同媒体账号而共享领取记录。

#### FR-7：回填只记录，不校验账号一致性

创作者回填作品信息，实现 UJ-4。

**Consequences（可验收结果）：**

- 创作者回填入口、表单、提交及反馈沿用现有流程，本次不新增关联账号只读区或其他交互优化。仅后台增加领取账号、实际回填链接等数据呈现。
- 记录本次领取关联账号与回填信息，不校验作品发布账号是否与领取关联账号一致。
- 不因账号不同而拦截回填、要求换号或判定无效；其他现有回填规则继续适用。
- 不引入 FR-003 的抖音号一致性校验、官方任务数据比对或新增分账判定。

### 4.5 后台关联账号展示

#### FR-8：领取记录回填数量弹窗展示关联账号

后台在「稿件管理－领取记录」列表点击本条记录的「回填数量」，弹窗增加领取关联账号内容，实现 UJ-4。

**Consequences（可验收结果）：**

- 入口位于领取记录列表，弹窗只对应当前领取，不改成稿件列表的汇总弹窗，不混入同一用户其他领取。
- 在现有回填明细弹窗中增加领取关联账号展示，结构可参考 FR-003 最新「管理后台－领取记录」；保留既有回填内容与数量口径。
- 弹窗展示领取账号的平台、昵称、账号 ID，桌面横排、窄屏竖排（D-4 已确认），以及本次实际回填链接等原回填明细；不混入其他领取记录或无关账号资料。
- 无领取要求且未选择账号的记录，不虚构领取关联账号。
- 无需关联账号的场景，关联账号空值统一显示「-」，不显示「未关联账号」或视为异常；已删除账号仍按领取时保存的信息展示。

## 5. 非目标

- 不做添加账号时的规则审核，不提供剪辑手人工审核、合作关系和合作用户名单。
- 不做每日 0 点抓取、定时更新、领取时刷新指标，不按真实平台最新数据自动重审。
- 不支持四个平台以外的账号，不限制同账号归属多个右豹用户，不设账号数量上限。
- 不校验回填账号一致性，不修改 FR-003 或其他迭代。
- 不设业务指标、统计周期、数值目标，不新增数据看板。
- 不新增素材类型详情、独立账号管理入口或页面，不改上传第一步与创作者回填交互；本轮仅同步文档，不接真实解析服务。

## 6. 非功能要求与依赖

- **准确性：** 区分解析失败、指标缺失和真实零值；≤、≥ 均含等号，启用项全部满足才可选择。
- **一致性：** 全部规则关闭时不得额外拦截账号；保存账号和符合领取要求为两种不同结果，不以不可选状态阻止账号保存。
- **归属与记录：** 账号列表归属右豹用户，同一社交媒体身份可由不同用户分别保存；领取关联和后台回填明细保持当前领取范围。
- **依赖：** 素材类型配置、截图所示上传稿件页面、媒体账号添加及列表、稿件领取、回填、领取记录及回填数量弹窗、四个平台主页解析。
- **设计前输入：** 已收到上传稿件截图，确认素材类型必填；其他相关已有页面仍需补齐。参考 FR-003 最新领取记录弹窗，不复制其独有审核及一致性规则。

## 7. 成功标准

以 FR-1 至 FR-8 验收：非负阈值含 0、三项独立开关和 AND 判断、全关直接领取、素材类型必填且上传后不可改、账号添加不审核、静态数据筛选可选项、多账号及删除、回填不校验一致性、领取记录弹窗展示关联账号。不设额外业务指标。
