# FR-wen-004 · 一键代发_报名领取稿件。 · v3 当前

业务线：右豹主业务（youbao）。本合同与 companions 共同定义实现及验收范围，依据 PRD v7、UX v2 和 2026-11-05 产品十项确认派生。需求名沿用需求单原话；能力 ID 保持 CAP-1 至 CAP-8。

本轮确认已同步到上游文档，D-1 至 D-4、E-1、E-2、S-1 均已收口。页面参考以当前确认版为准，历史日志只用于追溯；现有 Demo 后续按本合同核对。

## Why · 目的

平台需要按素材类型统一管理领取门槛，剪辑手可为各书籍稿件独立选择是否使用；创作者预存媒体账号后，用添加时的数据选择满足要求的账号领取，无需报名审核或与剪辑手建立合作关系。后台能按单次领取追溯关联账号，回填沿用原流程。

## Capabilities · 能力与验收

- **CAP-1 · 素材类型统一要求**（PRD FR-1）
  - **intent:** 后台人员能为不同素材类型分别设置领取门槛。
  - **success:** 沿用素材类型列表及居中新增/编辑弹窗，保留类型名称、用途，新增粉丝量、关注数、获赞数三行要求；素材类型列表不设详情查看操作，删除先确认。三项独立启用，新建时均不限制；启用项必须有 ≤ 或 ≥ 及非负阈值，允许 0 和小数。负数、非数字、缺项不能保存；全部启用项取 AND，边界含等号，全关无需账号直领。
- **CAP-2 · 规则生效与失败说明**（PRD FR-2）
  - **intent:** 创作者能看懂本次适用条件与账号不可选原因。
  - **success:** 展示启用指标、比较符与完整阈值；多项失败一次列出全部失败项、记录值及要求。规则保存后影响后续新进入的领取，不撤销历史领取，不改变已存账号事实；当前选择期间规则变化不替换本次判断。
- **CAP-3 · 按书籍稿件选择使用要求**（PRD FR-3、UX 当前修正）
  - **intent:** 剪辑手能在同次多书籍上传中分别决定是否使用统一领取要求。
  - **success:** 第一步「项目与投向」完全沿用现有流程和素材类型必填规则，本需求不修改。第二步依据第一步选择的素材类型：至少启用一项领取规则时，每本书卡片展示「领取稿件限制」，单选「不限制 / 使用平台统一限制」，默认不限制；三项全关时隐藏整组配置并按不使用处理，不保留隐藏的使用值。返回第一步更换类型后按新类型更新第二步显示。每卡片仅一组设置，同卡片多条内容上传后打包为一个稿件，整体使用该配置。使用时仅展示当前类型规则摘要；上传失败保留有效配置，成功后类型及使用选择锁定。后台后续改规则仍对新进入的领取生效。
- **CAP-4 · 添加媒体账号**（PRD FR-4）
  - **intent:** 创作者能保存主页链接解析出的账号身份和指标供后续领取使用。
  - **success:** 仅支持抖音、快手、小红书、视频号；填写发布平台和主页链接，昵称、账号 ID、粉丝量、关注数、获赞数全部识别才可保存，不因当前类型未启用某指标而省略。真实 0 有效，任一缺失或解析失败均不可保存；结果只读，不伪造指标。保存平台、链接、身份、三项指标及添加时解析时间；不满足稿件要求仍可添加，不产生待审核、通过、驳回或审核消息，后续不更新数据。
- **CAP-5 · 本人多账号管理**（PRD FR-5）
  - **intent:** 创作者能在领取账号选择弹窗内选择、删除本人账号并保留历史领取信息。
  - **success:** 暂不设独立账号管理页或「我的」入口；有要求的领取场景内管理账号，选择弹窗提供添加和删除。删除另弹二次确认，取消保留账号及原选择；删除已选账号后清空选择，未选新账号不能提交；删至空列表时显示添加引导。数量不设上限，逐个添加；本人按平台＋账号 ID 去重，不编辑或刷新原记录，跨右豹用户允许同一身份。删除确认后仅移除本人当前可选项，不联动他人或清空历史关联；删除后重加重新解析并生成新记录，不覆盖旧历史。
- **CAP-6 · 选择账号领取**（PRD FR-6）
  - **intent:** 创作者能从作品广场进入稿件详情，按稿件要求选择本人账号领取。
  - **success:** 沿用广场至稿件详情路径，保留试看、书籍信息、剩余素材、领取步骤、注意事项和原领取按钮，仅增加领取要求。不使用要求或三项全关时沿用原直接领取；有要求时，点击领取按钮先读取本人已添加账号；无账号直接弹窗提示去添加，不先打开空选择列表；有账号在当前详情覆盖底部账号选择 Sheet，按进入时的规则和本人已存指标判断。读取失败停留重试，不能当成无账号。四个平台均参与，不因稿件发布平台不同排除。不满足项禁选；全不满足引导新增满足账号；满足项单选一个且初始不预选。领取成功记录所选关联账号；提交不重新抓取、不按当前规则和已存数据重复校验，其他既有领取校验继续适用。关闭 Sheet 回同一详情且不领取；退出重进、换稿件或添加返回均重新判断并清空选择，不自动领取。
- **CAP-7 · 原流程回填**（PRD FR-7）
  - **intent:** 创作者能在原回填入口提交作品并保留领取关联信息。
  - **success:** 创作者回填入口、表单、提交及反馈完全沿用现有流程，本次不新增关联账号说明、选择或其他交互优化；作品发布账号不同不新增拦截、换号提示或无效判定，其余既有回填校验不变。不引入 FR-003 的账号一致性、官方任务比对或新增分账判断。
- **CAP-8 · 后台单次领取追溯**（PRD FR-8）
  - **intent:** 后台人员能在现有回填数量弹窗查看本次领取关联账号。
  - **success:** 入口固定为「稿件管理－领取记录」本条回填数量，弹窗展示本次领取账号（平台、昵称、账号 ID）及实际回填链接等原回填数据，不改成稿件汇总。无需关联显示「-」，删除后仍显示领取时身份；零条回填保留关联摘要，读取失败显示错误与重试，不能以「-」代替。原列表字段、数量、筛选与返回位置保持，摘要按已确认 D-4 桌面横排、窄屏竖排。

## Constraints · 约束

- “有领取要求”仅指稿件选择使用且素材类型至少启用一项；详情规则未加载或读取失败不能当成无要求直接领取。
- 账号身份以平台＋账号 ID 区分，账号记录归属于右豹用户；领取关联保存本次历史信息，不能只依赖可被删除的当前列表项展示历史。
- 资格判断只在进入账号选择时执行；本次提交失败重试保留选择和判断，不以重新解析为前提。已选账号并发失效且无法完成关联时，提示返回重选，不伪造领取成功，不追加指标或规则重审（E-2 已确认）。
- 完整状态、错误恢复、文案、响应式与无障碍遵循 DESIGN / EXPERIENCE 的当前有效条款：修改平台或主页链接清除旧解析结果，失败保留输入，写入中防重复；读取失败不伪装成空列表，不可选原因常驻且可读。
- 账号选择 Sheet 最高约 72%，列表内部滚动、底部操作固定，避开安全区及键盘；保留完整数值与全部失败原因，不仅显示“1万”等缩写。浮层关闭回触发项，Esc 只关闭最顶层，限制焦点并阻止底层误触；单选禁用原因可读，手机热区至少 44×44px。其余字号、对比、200% 放大与减少动态效果要求沿用 UX。
- 继承移动端、后台及迭代外壳既有配色和组件。后续 Demo 另开本 FR 页面，组件 class 复用仓库规范，不回改其他 FR；规则抽屉只写本 FR，业务流程在独立 Tab 手写 SVG，深链为 `?tab=fe|admin|flow`。
- 本次交付为合同文档重写。Demo 只用示例数据，不接真实接口、解析服务、登录、权限和持久化；成功反馈标注演示，不声称真实写入。截图存量字段和示例数值不构成新增功能或默认业务值。

## Non-goals · 非目标

- 独立媒体账号管理页面或入口、素材类型详情操作、上传第一步改造、创作者回填交互优化。
- 添加时的门槛审核、剪辑手人工审核、合作关系与名单、审核通知。
- 每日抓取、定时或领取时刷新指标、原记录编辑；批量导入、四平台外账号、账号数量上限或跨用户独占。
- 回填账号一致性、官方任务比对、新增分账判定、统计看板、业务指标目标或统计周期。
- 将 FR-003 的融合任务报名、接取任务、仅抖音号和资质审核扩展到本需求；重做上传、广场或后台系统。

## Success signal · 成功信号

- 后台居中弹窗保存统一要求；第一步沿用原流程；无规则类型在第二步隐藏配置，有规则时两本书分别选择使用/不使用，各卡片多条内容打包一个稿件，成功后配置锁定。有要求的稿件无账号先弹添加提示，有账号打开底部 Sheet，删除二次确认，粉丝 ≥1000 时 999 禁选、1000 可选，≤0 时真实0可选；全关且无账号仍可直领，多项失败一次展示完整原因。示例阈值不作为默认值。
- 完整但未达门槛账号可保存，缺一项不可保存；选择期间规则改变，本次不重审，重新进入按新规则判断。删除重加后新记录不覆盖历史；不同账号作品仍可按原规则回填，后台当前领取显示历史关联及实际回填链接，无需关联为「-」，不串记录。

## Confirmed decisions · 已确认口径

- D-2：不设独立账号入口或管理页，领取选择弹窗内选择与删除，删除二次确认。
- D-4：后台领取账号摘要为平台、昵称、账号 ID，桌面横排、窄屏竖排；实际回填链接属于本次领取的回填明细。
- E-1：添加账号分「识别账号 / 保存账号」两步，保存后返回来源领取场景重新判断，不自动选择或领取。
- E-2：账号并发失效导致无法关联时提示返回重选，不重审指标或规则。
- S-1：每本书卡片一组配置，多条内容打包为一个稿件；第三步只读核对，成功上传后锁定。

当前无剩余上述业务或设计待决项。
