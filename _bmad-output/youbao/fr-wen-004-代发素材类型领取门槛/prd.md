# FR-wen-004 · 代发素材类型领取门槛 · v9 当前

业务线：右豹主业务（youbao）

## 0. Document Purpose（文档目的）

本文件仅覆盖 FR-wen-004：后台按素材类型设置统一领取要求，剪辑手按稿件选择是否使用；创作者添加媒体账号，保存主页链接解析出的数据，领取时选择满足要求的账号；后台回填明细展示领取关联账号，并在稿件管理的「社交媒体账号」Tab 汇总所有用户的账号新增记录及删除状态。

全局编号为 `iteration_id: FR-wen-004`；正文 FR-n 仅表示本增量内部功能编号。本版沿用 v4 对 v3 的调整，替换原有 的报名自动审核及每日数据更新方案：添加账号只解析并保存，不做领取要求审核；资格仅在领取时校验，后续使用添加时记录的数据，不再抓取更新。仍不建立创作者与剪辑手的合作关系。

输入为同目录需求单、历轮产品确认、上传稿件截图，以及 2026-11-06 补充调整的《一键代发基础流程.png》和本次两轮补充结论。素材类型必填沿用现有规则；后台参考 FR-003 最新领取记录及回填数量弹窗，不引入其回填账号一致性校验。本版同步站内与站外领取、先领后填、超时释放、稿件粒度、上传锁定和规则生效边界，仅更新需求文档，既有 Demo 后续按合同核对。

## 1. Vision（愿景）

让创作者在有领取要求的领取场景中添加多个媒体账号，领取稿件时直接从账号列表选择满足目标素材类型要求的账号。账号无需按素材类型重复报名审核，也不与剪辑手建立长期合作资格。

平台通过粉丝量、关注数、获赞数统一管理领取门槛。账号数据固定为添加时的解析记录，系统按当前素材类型规则判断账号是否可选；规则不满足则在选择时说明原因，不阻止该账号保存到用户账号列表。

## 2. Target User（目标用户）

### 2.1 JTBD

| 用户 | 任务 | 结果 |
|---|---|---|
| 后台人员 | 按素材类型设置门槛，查看领取、回填及所有用户新增的社交媒体账号记录 | 统一准入规则，追溯本次领取关联及账号新增、删除状态 |
| 剪辑手 | 上传稿件，必选素材类型并选择是否使用统一要求 | 本稿件按确定配置提供领取 |
| 创作者 | 添加、删除媒体账号，选择满足要求的账号领取并回填 | 不等待审核，使用已保存账号数据完成领取判断 |

### 2.2 Non-Users（本期非目标用户）

本期不支持抖音、快手、小红书、视频号以外的平台账号；不支持剪辑手自定义指标阈值或人工审核用户。

### 2.3 UJ（关键用户旅程）

- **UJ-1：配置与供稿。** 后台在「素材类型」配置启用指标、比较符及阈值；剪辑手第一步沿用原流程选择素材类型，第二步仅有规则时逐书籍卡片选择是否使用，无规则隐藏；每卡片作为一个稿件，同卡成片共享整稿关键词。上传成功后所有内容仅可查看；素材审核驳回后重新上传，不编辑原稿件。
- **UJ-2：添加账号。** 创作者领取有要求的稿件，若账号列表为空，收到添加账号提示；选择平台、填写主页链接，系统解析资料、展示并保存到本人账号列表，不审核是否满足稿件要求。创作者可新增多个账号，也可删除账号。
- **UJ-3：选择账号领取。** 站内与站外私域均先按最新规则判断本人账号，选定账号进入领取流程后不再受规则变化影响，再进入关键词相关流程。先领后填也须先过门槛；占用后 1 小时内补关联关键词，成功关联才算领取成功并允许下载。超时释放稿件并退回积分／次数，历史关联保留为已超时；再次领取重新选账号。
- **UJ-4：回填与后台查看。** 创作者回填时不校验作品账号与领取关联账号一致性。后台进入「稿件管理－领取记录」，点击本条领取的「回填数量」，在弹窗中查看该次领取的关联账号及回填内容。
- **UJ-5：后台账号记录。** 后台进入「稿件管理－社交媒体账号」，查看所有用户成功新增的账号、主页链接、添加时三项指标、新增时间及正常／已删除状态；无需账号已领取稿件也能查看记录。

## 3. Glossary（术语表）

| 术语 | 定义 |
|---|---|
| 创作者 | 以右豹用户 ID 识别的用户，可保存多个媒体账号 |
| 媒体账号 | 抖音、快手、小红书或视频号账号；社交媒体身份以平台和账号 ID 区分，同一身份可归属多个右豹用户 |
| 添加账号 | 填写平台和主页链接，解析后保存到用户账号列表的行为；原“账号报名／报备”在本版均按此理解，不包含审核 |
| 账号记录 | 本右豹用户保存的平台、主页链接、账号昵称、账号 ID、粉丝量、关注数、获赞数及添加时解析时间；支持手动更新指标 |
| 素材类型 | 上传稿件的必填分类，也是后台统一领取要求的配置维度 |
| 统一领取要求 | 素材类型下启用的条件集合，每项为指标、≤ 或 ≥、非负阈值 |
| 有领取要求 | 稿件选择使用统一领取要求，且目标素材类型仍存在并至少启用一项限制 |
| 领取资格校验 | 领取时使用账号记录的数据逐项比较当前适用要求，全部启用项满足才允许选择 |
| 领取关联账号 | 本次领取选择并记录的媒体账号，不是剪辑手合作关系 |
| 素材稿件 | 一个书籍卡片作为一个素材稿件，同卡多成片打包并共享整稿关键词及领取要求 |

| 回填数量弹窗 | 在稿件管理的领取记录列表点击某条领取的回填数量后打开的明细弹窗，作用域为该条领取 |

## 4. Features（功能需求）

### 4.1 后台统一要求

#### FR-1：按素材类型配置领取要求

后台人员在「素材类型」设置领取要求，实现 UJ-1。

**Consequences（可验收结果）：**

- 粉丝量、关注数、获赞数各自支持是否参与限制；新建素材类型时三项均默认「不限制」，未启用项不参与判断。
- 每个启用项配置 ≤ 或 ≥ 和非负数阈值，阈值可为 0，不将 0 当成未填写；不把阈值限定为必须大于零的整数。
- 启用项条件填写完整后才可保存；负数、缺失比较符或缺失阈值不可保存。
- 多项启用取逻辑“且”，边界包含等号；任一项不满足即不能使用该账号领取。
- 三项全部关闭时，无需添加或选择账号，直接进入原关键词等领取流程；“直接领取”仅表示跳过账号门槛，不表示跳过关键词或提前允许下载。
- 不同素材类型分别配置，不混用规则。素材类型沿用居中新增/编辑弹窗，列表无需详情查看操作，删除先确认。
- 存量稿件的领取门槛开关默认无门槛，后台为素材类型配置规则不自动将存量稿件切换为使用要求。
- 删除被稿件引用的素材类型后，相关稿件的类型内容显示「-」，后续新发起领取改为无门槛；这是已确认的删除结果，不将普通规则读取失败误判为类型已删除。已经选定账号进入的本次领取不因后续规则变化重判，历史关联保留。

#### FR-2：规则变更与失败说明

系统在后续领取中使用当前适用规则，实现 UJ-3。

**Consequences（可验收结果）：**

- 后台保存变更后，在选择账号领取稿件时按最新规则判断；上传或添加账号期间规则变化同样以选择账号时最新规则为准。选定账号进入领取流程后，补关键词、提交和失败重试均沿用本次判断，不受后续规则变化影响。已完成领取的历史记录不追溯撤销，不覆盖其关联账号记录。
- 不存在需要随规则变更处理的报名审核状态，规则变化不改变账号保存事实。
- 向创作者展示当前启用指标的比较符与阈值。
- 账号不满足一项或多项条件时均禁止选择，卡片统一提示「本账号未满足要求」，不展开具体失败项；保留身份、三项指标及本次要求展示，不再采用逐项失败原因文案。
- 示例：粉丝量 ≥ 1000，账号记录为 999 时不满足，1000 时满足；粉丝量 ≤ 0 时，记录为 0 满足。示例不是默认规则。

### 4.2 剪辑手上传配置

#### FR-3：必选素材类型并选择是否使用要求

剪辑手按稿件选择是否使用平台统一领取要求，实现 UJ-1。

**Consequences（可验收结果）：**

- 上传第一步完全沿用现有流程，素材类型必填属既有规则，本需求不改第一步。第二步依据其所选类型决定是否显示领取规则配置。
- 所选类型至少启用一项领取规则时，第二步每本书卡片显示「领取稿件限制：不限制 / 使用平台统一限制」，默认不限制；三项全关时隐藏整组配置并按不使用处理，不保留隐藏的使用值。返回第一步更换类型后，按新类型更新第二步显示。
- 每本书卡片作为一个素材稿件，同卡片多条成片共享整稿关键词、领取要求及领取关联，不设逐内容不同开关。账号运营模式第三步沿用每稿件最多关联 5 个关键词，计数对象为整稿，不按成片重复计算；任务协作模式沿用原关键词规则。第三步只读核对，上传前修改回第二步；不允许剪辑手自定义阈值。
- 稿件上传成功后，素材类型、是否使用统一要求及其他所有稿件内容均不可修改，只能查看详情。保留原素材发布审核／免审流程；驳回后需重新上传稿件，不在原稿件信息内修改重提。上传失败尚未形成成功稿件时，保留有效输入供重试。
- 不使用时，不因本需求增加账号或指标限制，其他现有领取规则继续适用。
- 使用时取该素材类型当前统一规则；剪辑手上传后配置不可改，不妨碍平台后台修改统一规则后对后续领取生效。
- 三项全关与不使用统一要求均走无领取要求路径，不强制选择账号。

### 4.3 添加并保存媒体账号

#### FR-4：解析链接并保存账号，不进行报名审核

创作者添加媒体账号，实现 UJ-2。

**Consequences（可验收结果）：**

- 平台选项仅为抖音、快手、小红书、视频号；填写发布平台及账号主页链接。
- 系统通过主页链接识别账号昵称、账号 ID、粉丝量、关注数、获赞数，展示识别结果并保存到本人账号列表。
- 添加时不与任何素材类型要求比较，不产生待审核、审核通过或自动驳回状态，不发送报名审核结果消息。
- 即使指标不满足当前稿件要求，解析成功的账号仍可保存；能否领取由 FR-6 判断。
- 链接无效或解析失败时提示更正或重新尝试，不伪造成功数据，不用 0 代替缺失指标；真实识别出的 0 为有效值。
- 账号身份和粉丝量、关注数、获赞数三项指标均成功识别后才允许保存；任一必需信息缺失不可保存，不因目标素材类型未启用某指标而省略该指标解析。
- 账号保存后，后续领取均按该账号记录中的三项指标判断，不每日抓取、不自动刷新，也不在领取时重新解析。

#### FR-5：支持多账号与删除

- [2026-11-11 已调整] 复用现有后台社交媒体账号模块，不新增本 FR Tab；账号手动更新见最新调整。

**Consequences（可验收结果）：**

- 同一右豹用户可添加多个媒体账号，账号数量暂不设上限；逐个添加，不增加批量导入。
- 同一社交媒体账号可归属多个右豹用户，暂不限制；每位用户只能从本人保存的账号记录中选择，不直接展示其他用户列表。
- 选择弹窗提供添加与删除，删除须另弹二次确认；取消不改变原列表和选择。成功删除后移除该项，若为已选账号则清空选择；删至空列表时提示添加。删除失败保留原项并允许重试。
- 同一右豹用户重复添加相同平台和账号 ID 时去重，不新增重复账号记录；已保存账号不支持编辑。跨右豹用户仍可分别保存同一媒体账号。
- 删除后重新添加相同平台和账号 ID 时，重新解析并生成新账号记录；身份和三项指标均成功识别后保存。新记录不覆盖原历史领取关联信息，已保存且未删除的账号仍去重、不支持编辑或刷新。
- 删除只移除本人可选列表项，保留历史领取关联信息；不得因另一用户保存同账号而联动删除，也不修改既有领取事实。
- 账号添加表单可复用已有开白表单的账号字段，但不得沿用其审核流程；已有页面仍需在设计前补齐。

### 4.4 领取与回填

#### FR-6：按已保存的数据筛选并选择领取账号

创作者领取有要求的稿件时，检查本人账号列表并选择合格账号，实现 UJ-3。

**Consequences（可验收结果）：**

| 稿件与列表状态 | 处理 |
|---|---|
| 存量默认无门槛、不使用统一要求、素材类型三项全关或已删除 | 无需账号报备或选择，进入原关键词等领取流程，成功关联关键词后才允许下载 |
| 有领取要求，账号列表为空 | 点击领取后直接弹窗提示去添加媒体账号，不先展示空选择列表，不能跳过要求 |
| 有领取要求，已有账号 | 打开详情页底部选择弹窗，合格项可单选，记录一个关联账号后进入关键词相关流程 |
| 有领取要求，部分账号不满足 | 不满足项禁止选择，统一提示「本账号未满足要求」，满足项仍可选 |
| 有领取要求，全部账号不满足 | 提示添加满足领取要求的账号，不允许用不满足项领取 |

- 站内广场／详情与站外私域分享链接统一执行同一门槛，不因入口不同豁免。账号归属于当前右豹用户；站外添加或选择账号后继续来源稿件的领取流程。
- 点击有要求稿件的领取按钮先读取本人账号；读取失败提示重试，不当成空列表。已有账号则打开底部选择弹窗，无账号直接弹添加提示；添加按「识别账号 / 保存账号」两步，保存后返回来源稿件，按最新规则重新分流并清空选择，不自动领取；若此时已无门槛，则无需选择账号，继续原领取入口。
- 已选账号并发失效且无法关联时提示返回重选，不伪造成功，不追加指标或规则重审。
- 校验对象为账号记录保存的指标，不使用实时社交媒体数据，不因账号添加时间较早而自动刷新。
- 账号列表全平台复用，按本次目标稿件素材类型规则判断，不因曾符合另一个类型而免检。
- 发布平台不限制可选账号范围：本人已保存的四个平台账号均可按三项指标判断是否可选，不因稿件发布平台与账号平台不同而排除。此规则不扩展账号添加的四个平台范围。
- 选择账号领取时，用本人已存指标与最新素材类型规则判断可选性。选定账号并进入本次领取流程后固定该次判断，提交时不重新解析或重审；1 小时内补关键词及其申请返回属于本次流程继续，不属于重新发起领取。退出本次流程重新发起、换稿件或超时后再次领取时，按最新规则重新走流程并选择账号。
- 不建立剪辑手合作关系，不因另一个右豹用户使用相同媒体账号而共享领取记录。

**关键词、占用与下载衔接：**

- 本次账号选择及门槛判断位于关键词相关流程之前；包括先领后填，必须先通过账号门槛，不能先占用再校验。
- 通过后沿用原关联关键词自动选择、快捷提词申请及选词流程。选择先领后填时，先占用稿件并保留本次领取关联账号，在占用后 1 小时内补关联关键词；此期间沿用此前账号判断，不再重审。
- 成功关联关键词才判定稿件领取成功，成功后才可下载；仅选定账号、占用稿件或提交提词申请均不等同于领取成功。
- 占用超时后释放稿件，其他用户可领取；保留本次领取关联，记录状态为「已超时」，积分／次数退回。再次领取重新走完整流程、重新选账号，不复用超时记录的资格判断。
- 门槛判断在关键词流程之前，不改变原扣次数／积分及退款／退次规则；其余既有领取校验继续适用，不新增扣费或退款机制。
- 已领取成功的稿件再次下载无需做任何判断，直接下载，不再选账号、核验门槛或重新走关键词流程。

#### FR-7：回填只记录，不校验账号一致性

创作者回填作品信息，实现 UJ-4。

**Consequences（可验收结果）：**

- 创作者回填入口、表单、提交及反馈沿用现有流程，本次不新增关联账号只读区或其他交互优化。仅后台增加领取账号、实际回填链接等数据呈现。
- 记录本次领取关联账号与回填信息，不校验作品发布账号是否与领取关联账号一致。
- 不因账号不同而拦截回填、要求换号或判定无效；其他现有回填规则继续适用。
- 不引入 FR-003 的抖音号一致性校验、官方任务数据比对或新增分账判定。
