# 需求单

业务线：右豹主业务

需求名：代发素材类型领取门槛

编号：FR-wen-004

编号口径：FR-wen-004 为全局编号，PRD 正文 FR-n 仅为本需求内部条目。当前方案为 PRD v7，取代旧版合作关系、报名自动审核及每日指标更新方案。

照着哪条现有需求做：一键代发；账号添加可复用现有开白表单账号字段，不沿用审核；后台参考 FR-003 最新管理后台领取记录及回填数量弹窗，不引入其账号一致性校验。已收到上传稿件截图，素材类型必填。

谁在用：设置素材类型领取要求的后台人员；上传稿件并选择是否使用要求的剪辑手；添加、删除媒体账号并选择满足要求账号领取的创作者。

从哪个入口进来：后台素材类型设置；剪辑手上传稿件；创作者稿件详情领取、添加提示及领取账号选择弹窗；现有回填入口；后台「稿件管理－领取记录」列表的「回填数量」弹窗。

接着怎么点：

1. 后台按素材类型设置粉丝量、关注数、获赞数，每项支持独立启用或关闭、≤ 或 ≥ 和非负数阈值，允许设 0。新建素材类型三项均默认「不限制」。全部启用项需同时满足；三项全关无需添加或选择账号，用户可直接领取。
2. 后台规则保存后，后续领取使用最新规则，历史已领取记录不追溯撤销；多项不满足时一次展示全部失败项、记录值与要求。
3. 剪辑手第一步按现有流程选择素材类型，不作修改。第二步仅当所选类型至少启用一项规则时，每本书卡片展示领取限制设置，默认不限制；三项全关则隐藏设置并按不使用处理。每卡片一组配置，多条内容上传后打包为一个稿件，上传成功后不可更改配置。稿件使用的素材类型及使用要求选择固定，但后台统一规则可影响后续领取。
4. 不使用统一要求，或使用但三项全关时，不增加账号报备拦截，按现有规则直接领取。
5. 有领取要求时，检查用户是否添加媒体账号。点击领取先检查本人账号；为空则直接弹窗提示去添加，已有则打开账号选择弹窗；添加填写发布平台、主页链接，系统解析账号昵称、账号 ID、粉丝量、关注数、获赞数并保存到本人账号列表，显示识别结果。账号身份及三项指标均成功识别后才允许保存，任一缺失不可保存。
6. 平台仅支持抖音、快手、小红书、视频号。添加账号不做素材类型审核，不产生通过、驳回、待审核状态，不要求当下满足稿件条件才可保存。
7. 同一用户可添加多个账号，数量暂不设上限；同一社交媒体账号可归属多个右豹用户，暂不限制；同一用户相同平台及账号 ID 去重，不支持编辑。暂不设独立账号管理页或入口；在领取选择弹窗内选择、删除账号，删除另弹二次确认。支持删除本人账号，删除后从本人可选列表移除，历史领取关联信息保留，不联动其他用户。删除后重加同账号时重新解析并生成新记录，需身份与三项指标全部识别成功；不覆盖原历史关联。
8. 领取时按目标稿件素材类型的当前要求，比对账号记录中的数据。未满足的账号禁止选择并展示原因；无满足账号时提示添加满足要求的账号；有满足项时选择一个并记录为本次领取关联账号。发布平台不限制可选账号范围，四个平台已存账号均按指标判断。进入领取账号列表时判断可选性，领取提交时不再次使用已存数据和当前规则校验；选择后规则变化不追加重复校验，后续新进入领取使用最新规则。
9. 账号数据以添加时解析并保存的记录为准，后续不更新，不做每日 0 点抓取，也不在领取时实时刷新。
10. 创作者回填完全沿用现有流程，不设计本次交互优化；回填不校验作品账号与领取关联账号一致性，仅记录，其他现有回填规则继续适用。
11. 后台在「稿件管理－领取记录」点击本条领取的「回填数量」，在现有弹窗增加该次领取关联账号内容，不改成稿件列表的汇总入口。展示领取关联账号的平台、昵称、账号 ID（桌面横排、窄屏竖排）及实际回填链接等本条回填明细；无需关联场景空值显示「-」，删除后历史记录仍显示领取时保存的信息。

后台要看什么：

- 素材类型：三项指标的启用设置、比较符、非负阈值；新增/编辑用居中弹窗，列表无需详情查看操作。
- 稿件管理－领取记录：保留现有回填数量入口，弹窗增加本次领取关联账号。
- 不新增剪辑手合作用户数量或人工审核功能。

哪些情况不允许：

- 素材类型未填不可完成上传，上传后不可更改稿件配置。
- 负阈值及启用条件不完整不可保存；0 不得按空值处理。
- 有领取要求时，不满足要求的账号禁止选择，无合格账号不得跳过限制领取。
- 不在添加账号时因其不满足稿件门槛而拒绝保存，不伪造解析指标。
- 不自动更新已保存账号数据，不因回填账号不一致阻止回填。

这次不做的：

- 账号报名审核、剪辑手人工审核与合作关系、审核结果通知。
- 每日抓取、定时刷新或领取时重新抓取账号指标。
- 四个平台之外的账号、批量导入、账号数量限制或跨右豹用户独占限制。
- 回填账号一致性校验、其他迭代改动、新增数据看板。
- 不新增素材类型详情、独立账号管理页或入口，不改上传第一步或创作者回填交互；本轮同步文档，不修改 Demo，不接真实服务；不设业务指标、统计周期、数值目标。

已确认的补充口径：

- D-2 不设独立账号入口，D-4 三字段摘要、E-1 识别/保存两步、E-2 并发失效返回重选均确认。
- S-1 每本书卡片一组领取配置，多条内容打包为一个稿件。
- 当前无剩余上述业务或设计待决项。
