# FR-wen-004 · 代发素材类型领取门槛 · v5 当前

业务线：右豹主业务（youbao）。本合同与 companions 共同定义实现及验收范围，依据 PRD v9、DESIGN / EXPERIENCE v4 和 2026-11-06 基础业务流程最终确认派生。需求名沿用需求单原话；能力 ID 保持 CAP-1 至 CAP-9。

本轮确认已同步到上游文档，D-1 至 D-4、E-1、E-2、S-1 及基础流程检查项均已收口。页面参考以当前确认版为准，历史日志只用于追溯；本轮已按本合同同步静态 Demo，验证记录见 demo-final-build.md。

## Why · 目的

平台需要按素材类型统一管理领取门槛，剪辑手可为各书籍稿件独立选择是否使用；创作者预存媒体账号后，用添加时的数据选择满足要求的账号领取，无需报名审核或与剪辑手建立合作关系。后台能按单次领取追溯关联账号，回填沿用原流程。

## Capabilities · 能力与验收

- **CAP-1 · 素材类型统一要求**（PRD FR-1）
  - **intent:** 后台人员能为不同素材类型分别设置领取门槛。
  - **success:** 沿用素材类型列表及居中新增/编辑弹窗，保留类型名称、用途，新增粉丝量、关注数、获赞数三行要求；素材类型列表不设详情查看操作，删除先确认。三项独立启用，新建时均不限制；启用项必须有 ≤ 或 ≥ 及非负阈值，允许 0 和小数。负数、非数字、缺项不能保存；全部启用项取 AND，边界含等号，全关无需账号直领。
  - **boundaries:** 存量稿件的门槛开关默认无门槛；删除被引用类型后，稿件类型内容显示「-」，后续新领取无门槛。类型已删除与规则读取失败区分；无门槛仅跳过账号步骤，仍执行原关键词等流程，成功关联关键词后才能下载。
- **CAP-2 · 规则生效与失败说明**（PRD FR-2）
  - **intent:** 创作者能看懂本次适用条件与账号不可选原因。
  - **success:** 展示启用指标、比较符与完整阈值及账号三项完整数值；未满足统一提示「本账号未满足要求」，不展开具体失败项。上传或添加账号期间规则变化，以选择账号领取时最新规则判断；选定账号进入本次领取流程后，补关键词、提交和失败重试均沿用此前判断，不受规则变化影响。不撤销历史领取，不改变已存账号事实。
- **CAP-3 · 按书籍稿件选择使用要求**（PRD FR-3、UX 当前修正）
  - **intent:** 剪辑手能在同次多书籍上传中分别决定是否使用统一领取要求。
  - **success:** 第一步「项目与投向」完全沿用现有流程和素材类型必填规则，本需求不修改。第二步依据第一步选择的素材类型：至少启用一项领取规则时，每本书卡片展示「领取稿件限制」，单选「不限制 / 使用平台统一限制」，默认不限制；三项全关时隐藏整组配置并按不使用处理，不保留隐藏的使用值。返回第一步更换类型后按新类型更新第二步显示。一个书籍卡片作为一个素材稿件，同卡多成片共享整稿关键词与领取要求；账号运营模式第三步每稿最多 5 个关键词按整稿计算，任务协作沿用原关键词规则。使用时仅展示当前类型规则摘要；上传失败保留有效输入。成功上传后所有稿件内容仅可查看详情，不得修改；原素材审核驳回后重新上传，不在原记录修改重提。后台后续改规则以用户选择账号领取时最新规则判断。
- **CAP-4 · 添加媒体账号**（PRD FR-4）
  - **intent:** 创作者能保存主页链接解析出的账号身份和指标供后续领取使用。
  - **success:** 仅支持抖音、快手、小红书、视频号；填写发布平台和主页链接，昵称、账号 ID、粉丝量、关注数、获赞数全部识别才可保存，不因当前类型未启用某指标而省略。真实 0 有效，任一缺失或解析失败均不可保存；结果只读，不伪造指标。保存平台、链接、身份、三项指标及添加时解析时间；不满足稿件要求仍可添加，不产生待审核、通过、驳回或审核消息，后续不更新数据。
- **CAP-5 · 本人多账号管理**（PRD FR-5）
  - **intent:** 创作者能在领取账号选择弹窗内选择、删除本人账号并保留历史领取信息。
  - **success:** 暂不设创作者独立账号管理页或「我的」入口；有要求的领取场景内管理账号，选择弹窗提供添加和删除。删除另弹二次确认，取消保留账号及原选择；删除已选账号后清空选择，未选新账号不能提交；删至空列表时显示添加引导。数量不设上限，逐个添加；本人按平台＋账号 ID 去重，不编辑或刷新原记录，跨右豹用户允许同一身份。删除确认后仅移除本人当前可选项，不联动他人或清空历史关联；删除后重加重新解析并生成新记录，不覆盖旧历史。
- **CAP-6 · 选择账号领取**（PRD FR-6）
  - **intent:** 创作者从站内详情或站外私域分享链接领取，统一先判断账号门槛，再进入关键词相关流程。
  - **success:** 保留原详情、领取入口及来源稿件上下文；无门槛跳过账号步骤，有要求先读取本人账号。空列表直接弹添加提示，已有账号打开底部 Sheet；读取失败重试，不当成空列表。选择时按最新规则与本人已存指标判断，四平台均参与，不因稿件发布平台不同排除。不满足禁选并统一提示，全不满足引导添加；满足项单选且初始不预选。选定账号进入流程后保存本次关联和判断，不重抓、不因规则变化重审。关闭 Sheet 不领取；重新发起、换稿件、添加返回按最新规则重新分流并清空选择，不自动领取；添加返回已无门槛时不强制选择账号。
  - **keyword-and-download:** 账号门槛步骤在关键词流程之前，先领后填同样须先通过。关键词已关联自动选择、快捷提词申请及选词沿用原流程。先领后填先占用，1 小时内补关联关键词不重审账号；申请返回属于本次流程继续。成功关联关键词才算领取成功并可下载；占用、选账号及申请未完成均不得提前下载。
  - **timeout-and-repeat:** 占用超时释放稿件供他人领取，原关联保留、状态「已超时」，退回积分／次数；再次领取重走流程、重新选账号，新记录不覆盖原超时历史。原扣次积分及退款退次规则延续，本次不新增机制。已领取成功的稿件再次下载不作任何判断，直接下载。
- **CAP-7 · 原流程回填**（PRD FR-7）
  - **intent:** 创作者能在原回填入口提交作品并保留领取关联信息。
  - **success:** 创作者回填入口、表单、提交及反馈完全沿用现有流程，本次不新增关联账号说明、选择或其他交互优化；作品发布账号不同不新增拦截、换号提示或无效判定，其余既有回填校验不变。不引入 FR-003 的账号一致性、官方任务比对或新增分账判断。
- **CAP-8 · 后台单次领取追溯**（PRD FR-8）
  - **intent:** 后台人员能在现有回填数量弹窗查看本次领取关联账号。
  - **success:** 入口固定为「稿件管理－领取记录」本条回填数量，弹窗展示本次领取账号（平台、昵称、账号 ID）及实际回填链接等原回填数据，不改成稿件汇总。无需关联显示「-」，删除后仍显示领取时身份；零条回填保留关联摘要，读取失败显示错误与重试，不能以「-」代替。原列表字段、数量、筛选与返回位置保持，摘要按已确认 D-4 桌面横排、窄屏竖排。
  - **timeout-history:** 占用超时保留该次关联账号并标记「已超时」；该记录不等于领取成功。再次领取的记录独立追溯，不覆盖原关联。
- **CAP-9 · 后台社交媒体账号记录**（PRD FR-9）
  - **intent:** 后台人员在稿件管理集中查看所有用户成功新增的社交媒体账号记录。
  - **success:** Tab 顺序固定为「稿件列表 / 领取记录 / 结算明细 / 社交媒体账号」。新页按用户账号新增记录逐行展示九列：用户（右豹昵称、ID）、社交媒体账号（昵称、ID）、媒体平台（抖音、小红书、快手、视频号）、主页链接、粉丝数、关注数、获赞数、账号状态、新增时间；昵称和 ID 同列分行，主页链接可查看打开。指标为添加时保存值，真实 0 有效、不刷新；新增时间为账号成功保存时间，不用解析或领取时间替代。未领取、未达门槛的成功新增账号也在范围内；仅解析未保存、保存失败不产生记录。
  - **history:** 状态仅「正常 / 已删除」；用户删除后保留整行及原资料、指标、新增时间，状态改已删除，不联动其他用户或历史领取。删除重加生成正常新行，旧行仍已删除；本人未删除账号重复添加去重，不新增行；跨用户同账号分别记录。账号状态不等于平台封禁、审核状态、是否达标或领取已超时。
  - **interaction:** 复用现有后台 Tab、表格及状态样式，加载中、真实空记录、读取失败分开，失败可重试；本页为记录查看，不新增后台添加、编辑、删除、恢复账号操作。

## Constraints · 约束

- “有领取要求”仅指稿件选择使用、素材类型仍存在且至少启用一项；存量默认无门槛，类型删除后显示「-」且无门槛。详情规则未加载或读取失败不能当成已删除或无要求。
- 账号身份以平台＋账号 ID 区分，账号记录归属于右豹用户；领取关联保存本次历史信息，不能只依赖可被删除的当前列表项展示历史。
- 选择账号领取时使用最新规则，选定账号进入本次流程后不重复判断；补关键词、申请返回及失败重试保留本次关联和判断，不以重新解析为前提。已选账号并发失效且无法完成关联时，提示返回重选，不伪造成功，不追加指标或规则重审（E-2 已确认）；原流程结束后再次领取需重新选择。
- 完整状态、错误恢复、文案、响应式与无障碍遵循 DESIGN / EXPERIENCE 的当前有效条款：修改平台或主页链接清除旧解析结果，失败保留输入，写入中防重复；读取失败不伪装成空列表，不可选原因常驻且可读。
- 账号选择 Sheet 最高约 72%，列表内部滚动、底部操作固定，避开安全区及键盘；保留完整数值，不仅显示“1万”等缩写，禁选统一提示「本账号未满足要求」。浮层关闭回触发项，Esc 只关闭最顶层，限制焦点并阻止底层误触；单选禁用提示可读，手机热区至少 44×44px。其余字号、对比、200% 放大与减少动态效果要求沿用 UX。
- 继承移动端、后台及迭代外壳既有配色和组件。后续 Demo 另开本 FR 页面，组件 class 复用仓库规范，不回改其他 FR；规则抽屉只写本 FR，业务流程在独立 Tab 手写 SVG，深链为 `?tab=fe|admin|flow`。
- 本次交付为合同文档重写。Demo 只用示例数据，不接真实接口、解析服务、登录、权限和持久化；成功反馈标注演示，不声称真实写入。截图存量字段和示例数值不构成新增功能或默认业务值。

## Non-goals · 非目标

- 创作者独立媒体账号管理页面或入口、素材类型详情操作、上传第一步改造、创作者回填交互优化；后台 CAP-9 账号记录 Tab 在本次范围内。
- 添加时的门槛审核、剪辑手人工审核、合作关系与名单、审核通知。
- 每日抓取、定时或领取时刷新指标、原记录编辑；批量导入、四平台外账号、账号数量上限或跨用户独占。
- 回填账号一致性、官方任务比对、新增分账判定、统计看板、业务指标目标或统计周期。
- 将 FR-003 的融合任务报名、接取任务、仅抖音号和资质审核扩展到本需求；重做上传、广场或后台系统。

## Success signal · 成功信号

- CAP-9：第四个 Tab 为社交媒体账号，九列字段完整；新增保存后正常，未领稿亦可见；删除后已删除且资料保留；重加新旧两行独立，跨用户同身份不合并，重复保存不新增行；三指标静态、真实 0、新增时间以及空／加载／错误状态可验收。

- 后台规则含 0、小数、AND 及边界等号可验收；账号完整但未达门槛可保存，缺项不可保存；999 对 ≥1000 禁选、1000 可选，真实 0 对 ≤0 可选，统一未满足提示。示例不作为默认值。
- 一卡一稿，同卡成片共享关键词及要求；账号运营按整稿最多 5 个关键词；上传失败保留输入，成功后所有内容只读，素材驳回重新上传。存量默认无门槛；删除被引用类型后类型「-」、后续领取无门槛，读取失败仍拦截重试。
- 站内与站外同门槛，选择时最新规则，选定进入后不重审；上传或添加期间变化在选择时生效，添加返回已无门槛则不强制选账号。先领后填先过门槛，1 小时补关键词期间不重审，关联成功前不可下载，成功后才开放。
- 超时释放供他人领取，保留账号及已超时记录，退回积分／次数；再次领取重选账号、不覆盖旧记录。成功后的再次下载不作任何判断。扣次退款沿用原规则，1 小时补关键词与作品回填期限分开。
- 删除重加不覆盖历史；不同账号作品仍可按原规则回填，后台当前领取显示历史关联及实际链接，无关联「-」、零回填和读取失败区分，不串记录。

## Confirmed decisions · 已确认口径

- D-2：创作者不设独立账号入口或管理页，领取选择弹窗内选择与删除，删除二次确认；后台另增 CAP-9 社交媒体账号记录 Tab。
- D-4：后台领取账号摘要为平台、昵称、账号 ID，桌面横排、窄屏竖排；实际回填链接属于本次领取的回填明细。
- E-1：添加账号分「识别账号 / 保存账号」两步，保存后返回来源领取场景重新判断，不自动选择或领取。
- E-2：账号并发失效导致无法关联时提示返回重选，不重审指标或规则。
- S-1：一个书籍卡片作为一个素材稿件，同卡多成片共享整稿关键词及要求；第三步只读核对，成功上传后所有内容仅可查看，驳回重新上传。
- 2026-11-06 基础流程最终确认：站内／站外门槛、先领后填与超时、关键词成功节点、直接再次下载、存量无门槛、类型删除后无门槛、选择时最新规则和原扣次退款规则均按 CAP-1/2/3/6/8 验收，无剩余相关待决项。

当前无剩余上述业务或设计待决项。
