# FR-wen-004 · 代发素材类型领取门槛 · v4 当前

业务线：右豹主业务（youbao）。对应 PRD v9、SPEC v5、DESIGN v4，按 2026-11-06 基础业务流程讨论的最终结论更新。D-2、D-4、E-1、E-2、S-1 及本次检查项均已收口。视觉见 DESIGN.md；本轮已按当前合同同步静态 Demo，验证记录见 demo-final-build.md。

## Foundation（基础）

保存账号与符合稿件要求是两个结果。添加只解析保存，不审核；账号指标固定为添加时数据，不定时或领取时刷新。站内与站外私域均在关键词流程前判断门槛：选择账号时按最新规则判断，选定账号进入本次领取流程后不重审。先领后填在通过门槛后占用稿件，1 小时内补关键词不重审；成功关联关键词才算领取成功并可下载。超时释放、保留关联并标已超时、退回积分／次数；再次领取重新选账号。其余扣次、退款和作品回填规则沿用。

## Information Architecture（信息架构）

| 表面 | 入口、任务与返回 |
|---|---|
| S1 素材类型规则 | 素材类型列表进入居中新增/编辑弹窗；保存或取消回列表，不设详情查看操作，删除二次确认 |
| S2 上传配置 | 第一步完全沿用；第二步按所选素材类型决定是否展示每本书领取规则配置，第三步沿用确认上传 |
| S3 稿件详情 | 站内广场或站外私域分享链接进入来源稿件，统一执行门槛；无要求跳过账号步骤，有要求先读取本人账号，再进入关键词流程 |
| S4 创作者账号管理 | 创作者无独立页面或入口；本人账号选择、删除管理合并在 S6，不设置「我的 → 媒体账号」；后台汇总入口见 S9 |
| S5 添加账号 | S3 无账号提示或 S6 添加入口进入表单，识别、保存两步；保存后返回来源稿件按最新规则重新分流，有要求进 S6、无要求不强制选账号，取消返回来源 |
| S6 账号选择弹窗 | 有要求且已有账号时，详情上打开底部 Sheet；可选择或删除本人账号，删除另弹确认；关闭回同一详情 |
| S7 原回填流程 | 本次不设计交互优化，完全沿用现有入口、表单、提交、反馈 |
| S8 后台回填明细 | 稿件管理－领取记录本条回填数量进入原弹窗；增加领取账号、实际回填链接等数据，关闭回原行 |
| S9 后台社交媒体账号 | 稿件管理第四个 Tab「社交媒体账号」，位于结算明细右侧；集中查看所有用户账号新增记录，包含已删除记录 |

## Component & State Patterns（组件与状态）

### S1：统一要求

固定粉丝量、关注数、获赞数三行，各自启用或不限制，新建默认全关。启用项需 ≤ 或 ≥ 和非负阈值，允许 0、小数，全部启用项取 AND，边界含等号。缺项、负数、非数字阻止保存，逐项报错并聚焦首错；未启用条件不参与校验。

加载未完成不可保存，失败提供重试；保存失败保留草稿，取消不保存。成功只影响后续新进入领取，不撤销历史关联或改变已存账号事实。素材类型列表不提供详情查看，不因字段数改为编辑抽屉。

存量稿件默认无门槛。删除类型经二次确认后，被引用稿件的类型显示「-」，后续新发起领取无门槛；类型已删除与临时读取失败分开处理。已选定账号进入的本次领取不因后续变化重判，历史关联不清空。

### S2：上传

第一步完全沿用原流程和素材类型必填规则，本期不新增或调整控件、校验。第二步读取该类型规则：至少启用一项时，逐本书卡片显示「领取稿件限制：不限制 / 使用平台统一限制」，默认不限制；使用时展示规则只读摘要。三项全关则隐藏整组设置并按不使用处理，不能保留隐藏的使用值。返回第一步更换素材类型后按新类型更新显示。

每个书籍卡片作为一个素材稿件，卡片间互不影响，新卡片默认不限制；同卡多成片共享整稿关键词与领取配置。账号运营模式第三步每稿最多 5 个关键词按整稿计算，任务协作沿用原关键词规则。第三步只读核对，上传前需修改则回第二步；上传失败保留有效配置。成功上传后所有内容只能查看详情，素材类型、使用选择及其他稿件信息均不可修改；保留原素材审核／免审，驳回需重新上传，不编辑原记录。后台统一规则以后变化，以用户选择账号领取时最新规则判断，不把上传期间看到的阈值作为领取依据。

### S3 / S6：领取分流与账号选择

1. 站内详情和站外私域分享领取统一读取稿件要求；加载或读取失败不能当成无要求，失败只在领取门槛区域局部提示及重试，其他详情保持展示。添加、选择账号后仍继续来源稿件。
2. 存量默认无门槛、不使用要求、三项全关或类型已删除时跳过账号步骤，继续原关键词相关流程；不能将“直接领取”理解为已成功或已可下载。
3. 有要求时，用户点击领取按钮后先读取本人已添加账号。读取中防重复点击；读取失败提示重试，不能误报没有账号。
4. 本人账号为空时，直接弹「请先添加媒体账号」，操作为取消/添加账号；不先打开空选择列表。取消留在同一详情，添加进入 S5。
5. 已有账号时打开详情上的底部 Sheet，选择账号领取时按最新规则和已存指标判断可选性；上传或添加账号期间规则变化不沿用旧阈值。四个平台均参与，不能按稿件发布平台额外排除；不满足项禁选，统一提示「本账号未满足要求」，不展开具体失败项。全不满足提供「添加账号」入口。
6. 初始不预选，满足项单选一个，未选不可进入关键词流程，不显示底部解释提示。选定账号进入本次领取流程后固定该次账号及门槛判断，后续补关键词、提交和失败重试不刷新指标或用新规则复审；提交中防重复，失败保留本次选择和判断。
7. 当前没有已确认的账号关联失效业务场景，不提供独立演示入口；仅保留确认前账号记录不存在时返回重选的兜底，不将规则变化、平台掉线或账号删除后的历史关联解释为失效。
8. 关闭 Sheet 回同一详情且不领取。退出本次流程重新发起、换稿件、添加保存后返回均按最新规则重新分流并清空选择，不自动领取。添加返回若已无门槛则不再强制选账号。已经选定账号并进入本次流程后，补关键词及提词申请返回属于流程继续，不重审。读取失败显示错误，不伪装为空列表。

### 关键词衔接、先领后填与下载

账号门槛判断在所有关键词相关步骤之前；先领后填也必须先完成该步骤，不能先占用后校验。无门槛仅跳过账号步骤，后续关键词与下载规则相同。

| 本次流程阶段 | 行为与结果 |
|---|---|
| 门槛通过，选定账号进入流程 | 保留本次关联及判断，在同一稿件详情底部弹出项目关键词选择 Sheet，支持搜索与单选；选择后「选词领取」高亮可点击，未选禁用；尚不显示为领取成功 |
| 选择先领后填 | 先占用稿件，1 小时内补关联关键词；保留此前账号判断，不因规则变更或申请返回重审；占用期间不可下载 |
| 成功关联关键词 | 才判定领取成功并开放下载；其他原领取规则继续适用 |
| 占用超时 | 释放稿件供其他用户领取，原记录保留关联账号，状态「已超时」，积分／次数退回 |
| 超时后再次领取 | 重新走完整流程，按最新规则重新选账号，新的关联不覆盖原已超时记录 |
| 已领取成功后再次下载 | 无需任何判断，直接下载，不再选择账号、校验门槛或走关键词流程 |

扣次数／积分和退款／退次延续原规则；本次门槛步骤在关键词流程之前，不新增扣费或退款机制。1 小时是占用后补关键词的期限，与后续作品回填期限不同，后者沿用原流程，不新增或改写期限。

### S5：添加、去重与删除

发布平台仅抖音、快手、小红书、视频号，填写主页链接后先「识别账号」，再「保存账号」（E-1）。昵称、账号 ID 和三项指标全部识别才可保存，不因当前类型关闭某指标而省略；真实 0 有效，缺失明确提示，不用 0 代替失败。结果只读；平台或链接变化即清除旧结果，重新识别前不能保存。

不合稿件要求仍可保存完整账号，不产生审核状态。识别和保存中防重复，解析失败保留输入，保存失败保留结果；保存成功提示「账号已添加」，返回来源稿件按最新规则重新分流，有要求进入 S6、无要求不再强制选择账号，不自动选中或领取。取消不新增账号，返回原提示或选择场景。

本人账号按平台＋账号 ID 去重，重复提示已存在并沿用已有记录，不编辑或刷新；跨右豹用户可独立保存同一身份，数量不设上限，逐个添加。

S6 每张账号卡均可删除，不因不满足要求而隐藏删除。点击删除另弹二次确认：「删除『{昵称}』？」「删除后将从你的可选账号中移除，历史领取信息保留。」取消不改变账号和选择；确认中防重复，失败保留原项可重试。成功删除已选账号则清空选择，未重新选中满足项不能提交；最后一个删除后留在来源选择场景显示添加引导。关闭上层确认回 Sheet，焦点回原删除触发项；若触发项已删除则移至相邻账号或添加入口。

删除仅移除本人可选项，不联动他人或清空历史；删除后重加需重新解析全部信息并生成新记录，不覆盖历史领取关联。删除不触发后台指标规则重审。

### S7 / S8：原回填与后台追溯

创作者回填流程原样沿用，不新增关联账号只读区、必选项、换号提醒或其他交互优化。作品账号不同不拦截、不判无效，其他已有回填校验保留；不引入 FR-003 的一致性校验、官方任务比对或新分账判断。

后台点击本条领取的回填数量，只加载本条关联和回填信息。弹窗保留实际回填链接等原回填数据，并新增「领稿账号信息」列，展示平台、昵称、账号 ID 三字段，保留原字段与数量口径，不汇总到稿件或混入他人记录。

无关联整体「-」，不写「未关联账号」或画错误；已删账号仍展示领取时身份。零条回填时明细为空，已有领取摘要保留；读取失败展示错误及重试，不以「-」代替。关闭恢复筛选、滚动与来源行焦点。

占用超时记录显示「已超时」，保留本次关联账号供同一领取范围内追溯；再次领取形成独立记录，不覆盖该超时历史。

### S9：后台社交媒体账号记录

Tab 顺序为「稿件列表 / 领取记录 / 结算明细 / 社交媒体账号」，切换后显示所有用户成功保存的账号新增记录，不以是否领过稿件或是否达标筛选记录范围。未保存或保存失败不产生记录；不将本表当作稿件上传或领取明细。

表格列依次为：用户（右豹昵称、ID）、社交媒体账号（昵称、ID）、媒体平台（抖音、小红书、快手、视频号）、主页链接、粉丝数、关注数、获赞数、账号状态、新增时间。两种身份均在同列内分行展示昵称和 ID，长链接可查看打开；数字完整显示，真实 0 保留。三指标读取添加时保存数据，不自动更新；新增时间取该账号成功保存的时间，与解析时间、领取时间区分。

成功新增记录为「正常」；用户删除后同一行改为「已删除」，保留原账号资料、主页、指标、新增时间，不移除后台行或历史领取关联。删除重加另生正常新行，旧行仍已删除；本人未删除身份重复添加不增加行；不同用户保存同一身份分别展示，不互相联动。账号状态仅指当前用户这条账号记录是否删除，与达标、平台封禁、审核、领取超时无关。

沿用后台表格与分页组件；加载中提供加载反馈，无数据展示空态，读取失败展示错误和重试，不伪装为空态。本页为记录查看，不新增后台修改账号的操作。此后台入口不改变创作者只在领取 Sheet 内管理本人账号的边界。

## Voice and Tone（文案）

要求标题使用「稿件领取要求（需全满足）」。选择列表不显示数据口径说明、解析时间及底部选择提示；不满足时统一显示「本账号未满足要求」。真实数据展示完整值，不把“1万”当唯一值。

解析失败提示检查平台和主页链接；指标缺失指出具体字段；重复提示「该账号已在你的媒体账号列表中」。保存成功不写审核通过、获得资格或合作成功。静态 Demo 成功反馈标演示，不声称真实平台写入。

## Accessibility & Responsive（可访问性与响应式）

手机单列，Sheet 最高约 72%，列表内部滚动，底部操作固定并避开安全区、键盘；添加子页隐藏主底栏，主页面不因弹窗挤窄。支持系统字号及 200% 放大，减少动态效果时去掉非必要滑入。

输入带 label，比较符提供可读名称，0 不按空处理；单选用正确语义，禁选原因 aria-describedby 关联且可阅读。错误就近常驻，首错聚焦；识别、保存和加载结果用合适 live region 宣告，不反复抢焦点。

所有弹窗带标题、dialog 语义、关闭操作、焦点限制和底层防误触；Esc 仅关闭最顶层，关闭回触发项，删除不能以点遮罩代替确认。手机热区至少 44×44px，后台文字链扩大热区，图标有可读名称。对比目标见 DESIGN.md，颜色不作唯一状态表达。

后台窄屏表格横向滚动、操作可达；弹窗宽不超过 calc(100vw - 32px)、最大高 85vh，内部滚动。

## Key Flows（关键旅程与验收）

- UJ-1：后台居中弹窗配置规则；剪辑手第一步沿用，第二步无规则隐藏、有规则按书籍卡片设置，第三步确认；一卡一稿、多成片共享整稿关键词；上传成功后所有内容只读，驳回重新上传。
- UJ-2：有要求稿件点击领取，无账号直接提示添加；识别完整即能保存，即使未达门槛也不阻止；返回选择重新判断。已有账号在选择弹窗中删除，二次确认，历史不变。
- UJ-3：站内与站外私域同门槛；已有四平台账号选择时按最新规则判断，999 对 ≥1000 禁选、1000 可选，真实 0 对 ≤0 可选；失败统一提示「本账号未满足要求」。选定进入本次流程后不重审，重新发起使用最新值。示例不作为默认规则。
- UJ-4：原流程回填不同账号作品仍可按既有规则提交；后台本条回填数量显示历史领取身份及实际链接，无关联「-」、零回填和读取失败区分，不串记录。
- UJ-5：稿件管理第四个 Tab 查看所有用户账号新增记录；九列完整、未领取仍可见、用户删除后保留已删除行、重加另行、跨用户隔离、静态指标及成功保存时间；加载、空态和读取失败区分。
- 边界验收：先领后填先过门槛、占用不可下载、1 小时补关键词不重审、关联成功才开放下载；超时释放、退回积分／次数并保留关联及已超时状态，再次领取重新选账号；成功后的再次下载直接放行。
- 默认及变更验收：存量稿件无门槛；删除被引用类型后稿件类型「-」、后续领取无门槛；上传或添加期间规则变化以选择账号时最新规则为准，添加返回已无门槛则不强制选账号。
