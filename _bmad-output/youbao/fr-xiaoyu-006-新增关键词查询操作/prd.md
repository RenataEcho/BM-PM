# FR-XIAOYU-006 · 新增关键词查询操作

右豹主业务 · 待开始

## 用户与目标
推广用户在项目关键词列表批量查询最新状态，逐词确认受理结果、更新状态与成功更新时间。

## 功能与验收
项目字段「是否可查询关键词」默认为空，仅设为「是」时在关键词列表展示入口。仅「审核成功待发布」「已发布」可参与更新。

单次最多提交 20 个关键词。单个关键词累计最多更新 3 次，每个用户每日最多更新 50 个关键词，跨项目累计，每日 23:59:59 重置。按实际受理的更新行为计次，失败也计次，同词重复更新分别计次，未受理不计次。

前端按当日剩余额度限制勾选，超出部分禁止勾选，取消后可改选。后端提交时复核，逐词返回受理或拒绝结果。仅受理项进入更新中，未受理项保留原更新状态。重复操作提示「关键词正在更新中，为避免数据异常请勿操作」。

接口推送更新成功或更新失败，成功时将接口时间戳转为日期和时分秒展示。
