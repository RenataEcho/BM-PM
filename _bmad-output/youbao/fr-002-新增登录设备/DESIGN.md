# FR-002 · 新增登录设备 · DESIGN

## 依据
以本需求 PRD、已确认本地 UX 为功能依据；视觉沿用 docs/design/移动端设计规范.md，外壳沿用 iteration-shell，组件沿用 component-spec-demo.html。

## 页面
- App、小程序沿用相同信息结构；设置入口并入列表，不独立成卡。
- 标题“登录设备”；顶部浅橙安全提示；当前设备置顶并标本机；历史记录按登录时间倒序。
- 白卡、浅灰底、12px 左右间距；紧凑行距；品牌橙 #ff4d22，浅橙 #fff1ec；不使用迭代外壳蓝紫作为手机主色。
- 标题应用名称＋登录端；型号、完整设备 ID 与登录时间作为补充。其他记录右侧下线，本机无操作。
- 下线弹窗位于手机内中央，覆盖而不挤压页面，取消和确认；成功清除记录，不展示“已下线”条目。
- 无其他记录展示“暂无其他登录设备”。

## 交付外壳
