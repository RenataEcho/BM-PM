# FR-002 · 新增登录设备 · EXPERIENCE

1. 设置列表点击登录设备，进入当前账号列表；返回设置保持入口位置。
2. 本机置顶、无下线；其他有效记录可下线。列表排序、去重与字段口径以 PRD 为准。
3. 点击下线 → 二次确认 → 取消保持记录；确认成功清除记录及分隔线；最后一条清除展示空态。
4. 失败保留记录并提示“下线失败，请重试”；目标已下线则清除记录。
5. 被下线端提示“当前登录已被下线，请重新登录”；旧 token 与续期不可继续用，未选记录不受影响。
6. 切换账号重新加载对应数据；同设备不同端独立，PC 不同浏览器独立；重新登录更新原记录。
7. Demo 场景包含设置、App 列表、小程序列表、空态、失败、已下线、目标端失效；场景重置仅内存，不执行真实请求。
8. 页签支持 ?tab=fe|flow；规则抽屉支持关闭按钮、遮罩、Esc；业务流程仅在页内 Tab 展示。
