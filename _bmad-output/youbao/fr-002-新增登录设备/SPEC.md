# FR-002 · 新增登录设备 · SPEC

## 范围与优先级
DESIGN / EXPERIENCE → prd.md → Demo。无管理后台新增；PC 仅采集与被下线。状态待开始，负责人 yu，提交 product-yu。

## 数据合同
每条展示记录可定位账号、设备、端及 PC 浏览器，关联全部有效凭证；返回应用标识、名称、端、可用型号、设备 ID、最近成功登录时间、本机状态。不得返回原始 token 给设备列表。请求仅能管理当前账号，不能仅凭客户端传入的设备 ID 下线其他账号。

## 行为合同
- 同账号同设备同端一条；PC 按浏览器独立。重新登录更新、续期不改登录时间。
- 三端可同时登录；本机不可通过列表下线；应用关闭不算下线。
- 下线成功：关联全部有效 token 及续期凭证失效，再清除记录。
- 失败：保留并提示重试；已下线：清除；退出或异常失效：清除。
- 目标端下次新业务和续期不可通过；通知或下次请求获知失效后进入重新登录；其他记录不受影响。
- 操作后的重新登录与并发处理须保证旧凭证不可复活，不误撤销其他账号。

## 验收
依据需求单第 7 节及 PRD Consequences；覆盖成功、取消、失败、重复操作、空态、多浏览器、账号切换、全部凭证撤销。

## 研发核对
设备与浏览器标识、旧记录兼容、服务端原子撤销机制、异常清理和通知路径；不在本 Demo 接真实接口。
