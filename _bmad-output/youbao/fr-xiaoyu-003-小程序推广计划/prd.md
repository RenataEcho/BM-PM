# FR-XIAOYU-003 · 小程序推广计划
业务线为右豹主业务，版本 v1，状态待开始。
## Document Purpose
本文件覆盖小程序推广计划接入与 UX。FR-n 为本增量功能序号。Demo 为 demo/iteration/fr-xiaoyu-003.html。
## Vision
运营同步并发布第三方任务，达人查找参与，后台核对分佣与流水。
## Target User
JTBD 为运营完成配置与查账、达人查看任务并参与。Non-Users 为在推广视频下购买的观众。UJ 为后台配置上架后，达人查看任务并赴抖音参与。
## Glossary
项目方为任务对应的内容提供方。通用规则按订单类型和用户身份匹配。自定义规则按任务 ID 匹配。
## Features
FR-1 项目配置与同步，验收为新增项目和任务列表可见。
FR-2 比例配置与删除，验收为新规则创建生效、删除后从列表移除。
FR-3 前端连续交互，验收为项目到任务到详情可返回。
FR-4 分佣试算，验收为输入金额和比例后展示计算过程。
FR-5 流水管理，验收为展示约定字段并支持查询反馈。
## 非目标
本原型不连接真实接口、登录、权限或持久化。
## 已确认规则

- 管理后台含项目方管理、任务管理、比例设置、分佣计算规则、流水管理。
- 接入撮合中介查询任务 ID、查询任务详情接口。任务归属与上架由后端处理，后台展示结果。
- 手动新增填写任务路径，查出任务 ID 后去重入库。
- 任务自定义规则优先，未命中按订单类型和右豹用户身份匹配通用规则。
- 修改比例通过删除旧规则、新建规则完成。删除后失效，新规则按创建时间生效。已取消回收站。
- 自定义规则删除后的空档期使用通用规则，历史流水保留原比例与计算结果。
- 分佣计算规则说明收入基数、佣金计算、用户归属及发放。试算仅用于业务口径评审。
- 前端仅展示已上架任务，项目列表进入项目任务列表，再进入详情和参与入口。
