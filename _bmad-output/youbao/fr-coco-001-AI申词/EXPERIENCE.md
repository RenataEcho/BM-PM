# EXPERIENCE · AI申词

视觉以 `DESIGN.md` 为准。这里只写这一页怎么走。和 Demo 不一致时改 Demo。

## Foundation

- **Form-factor**：移动端 H5，在前端交互 Tab 居中展示，页面宽 375px，不使用手机外壳。
- **UI system**：C 端沿用 `docs/design/移动端设计规范.md`。H5 外的迭代台沿用 `docs/design/iteration-shell/`。
- **入口**：一个移动端 H5 工具页。没有 App 底栏。
- 后台不看申请记录；每日免费次数和超出后每次积分消耗复用已有后台配置能力，本需求不新增后台页面。

## Information Architecture

| 画面 | 谁落地 | 上面有什么 |
|---|---|---|
| 申词 | UJ-1 | 顶部状态栏。当前项目入口；点击后用底部浮层选择项目并确认切换。逐行输入书籍 ID，「书籍 ID」字段标题右侧依次为「添加」「提取书籍信息」。成功或失败状态紧贴各自输入框显示，不另起信息卡；点成功书名看详情浮层。统一申请数量。AI 申词结果按书分芯片。页头去申请记录。底部并排：左 AI 申词（出词后改为重新申请），右立即题词 |
| 申请记录 | UJ-2 | 返回申词。条数。每条：项目、类型（AI申词或立即题词）、状态、时间（`YYYY-MM-DD HH:mm:ss`）；AI申词记录标明免费使用或实际消耗积分；按书列出书籍 ID、每本词数和本次申请词，或题词提交结果。关掉再打开还在 |

提取成功后只在对应输入框下显示紧凑的可点击书名，不显示书籍 ID。点名称在当前 H5 上打开从底部展开的书籍信息浮层，不使用居中弹窗；浮层展示书籍 ID、名称、简介、封面和链接，关闭后输入状态不变。点链接不离开这个 H5。

## Voice and Tone

申请是进行 AI 申词。题词是走现有的关键词题词接口。页面上就用这两个词。

反馈只说「提交成功」或「提交失败」。示例数据标明是示例。

## Component Patterns

- 项目是字节系项目，例如番茄小说、红果短剧。申词页只显示当前项目横向入口，字标加名称和箭头。
- 点项目入口打开底部「选择项目」浮层。浮层有说明、纵向项目列表、选中勾、关闭按钮和「确定切换」。点列表项只修改待确认项目；确认后切换并清空当前词和提交反馈，关闭或点遮罩不切换。
- 添加书籍不设页签和官方推荐。每行只填一个 ID；「书籍 ID」字段标题右侧依次放「添加」「提取书籍信息」。点击「添加」增加空白输入行，按 Enter 不添加；附加输入行可移除。含逗号或空格分隔的多个 ID 时不拆分，并提示「每行仅填写一个书籍 ID」。
- 至少有一个非空 ID，且没有格式错误或重复 ID 时，可以统一点击「提取书籍信息」。重复 ID 提示「书籍 ID 重复」。
- 提取中逐行显示加载状态，统一提取按钮不可重复点击。成功后在输入框下方显示紧凑的可点击书名，不显示书籍 ID，也不生成独立书籍卡片。
- 失败或空结果在输入框下方显示「未提取到信息」和文字按钮「重新提取」；输入行仍可通过行尾 × 移除，不允许手填书名。
- 点击成功书名打开底部详情浮层，展示书籍 ID、名称、简介、封面和链接。浮层不是居中弹窗；链接只展示，不离开这个 H5。
- 统一申请数量用于本次每一本书。每本书 1 到 10 个。超出范围时不能点 AI 申词，并提示请输入 1–10 之间的数量。
- 词按书分组，以芯片横排。每本书独立生成。
- 页面顶部有状态栏。
- 底部固定两枚按钮，不跟着内容滚走。左边未出词时是 AI 申词；词出齐后，同一枚按钮改为重新申请。右边是立即题词。
- 底部按钮上方持续展示当日剩余免费次数；AI 申词和重新申请共用该额度。
- 免费次数内点击后直接生成并减少一次额度；免费次数用完后先打开积分确认浮层，展示动态积分数、当前余额，并明确说明积分用于 AI 算力消耗。
- 确认后扣积分并生成；取消不扣不生成。积分不足时禁用确认并提示「积分不足，无法发起 AI 申词」。
- 点重新申请时，每一本书的词按新结果替换，并再留一条 AI申词记录。
- 出词时先显示正在生成，再按书出现整组词。
- 真正生成时用 `addendum.md` 里的提示词。系统提示词固定。用户提示词依次是 batchHeader、本批剧数据 JSON、batchRules、输出 JSON 结构。每个别名 4 到 10 个汉字，并原样返回 recordIndex。Demo 仍用示例词，不调用模型。
- 换项目、换书或改数量后，当前这批词和提交反馈清掉，要重新 AI 申词。
- 字节系项目点立即题词后先打开「选择推广类型」弹窗；类型必选且无默认值，取消或关闭不提交。点「确认题词」后携带所选类型走现有关键词题词接口，不再增加其他确认层。
- 页面只反馈提交成功或失败，并有一条短提示。失败没有其他动作，保留当前页。
- 成功也同样留在当前页，只显示提交成功。
- 申词完成留一条类型为 AI申词 的记录。立即题词另留一条，带提交成功或提交失败。
- 存在待提取、提取中或提取失败项时不能 AI 申词；用户需提取成功或移除相应项。
- 示例里点立即题词默认提交成功。场景「提交失败」固定失败，方便对照。Demo 不接持久化。

## State Patterns

| 状态 | 申词页 |
|---|---|
| 还没选齐 | 项目、书、数量缺一项时，AI 申词不可点 |
| 待提取 | 手动输入的 ID 尚未提取；AI 申词不可点 |
| 提取中 | 各行显示加载状态；提取按钮和 AI 申词不可点 |
| 部分失败 | 失败项显示「未提取到信息」，可重新提取或移除；AI 申词不可点 |
| 有免费次数 | 展示今日剩余免费次数；点击 AI 申词或重新申请后直接生成 |
| 免费次数用完 | 点击生成按钮打开积分确认浮层，说明用于 AI 算力消耗 |
| 积分不足 | 确认按钮不可点，提示积分不足，不发起生成 |
| 出词中 | 按书显示正在生成。出完之前，两个底部按钮不可点 |
| 词已出 | 左侧按钮改为重新申请，右侧立即题词可点 |
| 提交成功 | 当前页显示提交成功，词还在 |
| 提交失败 | 当前页显示提交失败，词还在，没有跳转 |

申请记录页只有列表。没有空操作按钮。还没有记录时，说明还没有申请记录。

## Interaction Primitives

- 点当前项目入口：打开选择项目浮层。点项目项：修改待确认项目。点「确定切换」：应用并关闭；点关闭或遮罩：放弃本次选择。
- 逐行填写书籍 ID；需要多本时点击字段标题右侧的「添加」增加输入行，填完后点击其右侧的「提取书籍信息」。
- 点提取成功的书籍名称：打开书籍信息浮层。点关闭：回到原列表状态。
- 填写统一申请数量。这个数量是每一本书各出多少个词。
- 点底部左侧按钮：未出词时是 AI 申词，每一本书开始出词。出词后同一按钮变为重新申请，按新结果替换。
- 免费次数用完后点底部左侧按钮：先确认本次动态积分消耗；确认后生成，取消不处理。
- 点底部立即题词：字节系项目先选择必填推广类型，再点「确认题词」提交并留下成功或失败。
- 点申请记录：进入只读列表。点返回：回到申词页，刚才的词和反馈还在。

## Accessibility Floor

主按钮和选中项不只用颜色区分，选中项有字重。反馈句放在词列表附近，不靠颜色单独表达成功或失败。点击目标不小于 44px 高。

## Key Flows

**UJ-1. 小明用 AI 想词，然后题词。**

小明要给右豹主业务里需要题词的项目交词。他打开这个 H5。

1. 点击当前项目入口，在底部浮层选择一个项目，再点「确定切换」。
2. 每行输入一个书籍 ID；需要多本时点字段标题右侧的「添加」增加输入行，再点其右侧的「提取书籍信息」。成功项在输入框下方显示紧凑书名入口，不显示 ID；点名称可在浮层查看书籍 ID、名称、简介、封面和链接。失败项在输入框下方显示「未提取到信息」和「重新提取」，输入行仍可移除。
3. 填写统一申请数量。这个数用于每一本书，每本 1 到 10 个。
4. 点底部左侧的 AI 申词。免费次数内直接生成；免费次数用完后确认本次积分用于 AI 算力消耗，再生成每一本书的词。
5. 不满意时，左侧按钮已变成重新申请。点它沿用相同免费/积分规则，每一本书的词换成新的结果。
6. 满意就点右侧立即题词。选择字节系题词必填的推广类型，再点「确认题词」携带所选类型直接提交。

高潮：页面告诉他提交成功，或提交失败。失败就停在这一页。

**UJ-2. 小明查看申请记录。**

1. 在这个 H5 打开申请记录。
2. 一条里看到项目、类型、状态、时间，以及每本书的 ID、数量和词，或题词是否提交成功。时间是 `YYYY-MM-DD HH:mm:ss`。关掉再打开，记录还在。
3. 看完即结束。记录上没有下一步。

## Responsive & Platform

前端交互直接展示完整可操作页面，不设左侧场景栏；居中展示 375px 宽的页面，不使用手机外壳，不缩放、不随桌面横向拉伸。页面高度适配 Demo 台，保留当前项目入口、选择项目浮层、选书、申词结果和固定底部操作；通过页面内操作进入申请记录并返回。业务流程仍在独立 Tab。


### 研发对照规则栏

前端交互采用左侧规则、右侧 375px H5 的布局，无手机外壳。左栏独立滚动，展示当前页面的字段、交互、状态与边界；申请记录与申词页切换时同步更新。左栏与完整需求抽屉复用同一份结构化规则，提示词仅留在抽屉，业务流程指向独立 Tab。


### 本地规则编辑

左侧规则区提供「编辑规则／保存到项目／取消」。使用 ## 分区标题与 - 规则条目编辑当前页面规则，保存至同目录 frontend-rules.json；刷新读取保存结果，抽屉与左栏同步。通过 python3 scripts/preview_server.py 启动本地服务。格式错误、保存失败或并发修改时保留输入并提示；取消不写文件。此能力仅编辑研发说明，不改变 H5 示例数据，也不自动改写 PRD 或视觉、交互合同。


### 字节系题词 · 推广类型

字节系项目点击「立即题词」先选择推广类型（必选），确认后携带所选类型走题词接口；未选择不可确认，取消不提交。类型：真人出镜、图文、解压TTS、解说混剪、meme剪辑、AIGC、营销号、沙雕漫、AI数字人、滚屏素材。

交互采用「选择推广类型」弹窗，单选下拉，不设默认值。确认按钮为「确认题词」；关闭或取消保留当前申词结果。Demo 仅模拟提交反馈，不接真实接口。[ASSUMPTION] 所选类型适用于本次所有书籍；接口字段名及枚举编码待接口方确认。
