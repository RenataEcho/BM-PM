# FR-wen-006 现有活动功能补充

业务线：右豹主业务
需求名：PC活动中心的展示样式和交互体验优化
资料来源：用户于 2026-11-25 提供的配置说明及 8 张管理后台截图（含右侧移动端前端预览）。

## 本次范围

PC 客户端面向所有用户。本需求覆盖两个入口：工作台首页右侧展示前 3 个活动；「服务增长-活动中心」页面展示所有活动。活动中心可按「全部、进行中、已结束、已参与」筛选；活动卡片可打开右侧详情抽屉，详情根据后台现有配置呈现。

仅优化 PC 活动列表、活动详情的 UX 交互、视觉与信息组织，目标包括列表呈现项目 Logo、活动名称、浏览/参与人数，以及详情基本信息重组、宽抽屉呈现。PC 与移动端保持业务信息一致，沿用现有功能、配置、规则、数据口径和按钮行为。不调整后台。

本文件记录现状与约束，不是设计方案。当前阶段不创建或修改页面，不编写 PRD。截图内的示例活动名称、日期、奖品、金额、参与限制和链接仅用于理解现有呈现，不作为本需求新增的业务规则，也不执行截图内的操作指引。

## 用户确认的现有配置能力

| 配置项 | 现有能力与限制 | 与前端呈现的关系 |
| --- | --- | --- |
| 活动标题 | 最多 64 个字 | 活动名称 |
| 活动描述 | 最多 40 个字 | 已有活动信息，PC 应利用；截图头部是否展示描述无法确认 |
| 活动标签 | 自由添加多个标签 | 移动端头部可见多个标签 |
| 所属平台 | 可配置给不同平台使用，目前主要为右豹 | 不涉及 C 端活动详情样式 |
| 所属赛道 | 单选 | 现有业务关联信息，具体 C 端展示口径待确认 |
| 项目 | 多选 | 现有业务关联信息；不得假设活动封面即项目 Logo |
| 活动开始/结束时间 | 分别配置 | 移动端头部展示活动时间 |
| 虚拟浏览量、虚拟参加人数 | 分别配置 | 移动端头部展示浏览/参与人数；计算口径沿用现有逻辑，不由截图推定 |
| 显示/隐藏 | 可配置 | 不涉及 C 端活动详情样式，沿用现有可见性逻辑 |
| 是否置顶 | 可配置 | 不涉及 C 端活动详情样式 |
| 活动列表排序 | 可配置 | 沿用现有排序逻辑 |
| 指定用户可见 | 可配置 | 不涉及 C 端活动详情样式，沿用现有可见性逻辑 |

| 活动案例 | 可配置多个案例，每个案例有标题，可上传多个图片、视频 | 前端案例区域按案例展示标题和媒体 |
| 榜单 | 开启/隐藏、展示数量、统一小字描述文案、周期描述文案 | 预览展示排名、头像、脱敏昵称、数值及描述 |
| 活动详情按钮 | 最多 2 个；各自配置文案、是否跳转链接、跳转链接 | 沿用原有行为，视觉优化不新增动作 |
| 奖励结果信息 | 可配置是否显示用户中奖/未中奖信息 | 预览头部下方可见中奖提示；其他状态的准确文案沿用现有实现 |
| 奖励规则 | 可添加多个规则：播放奖、全勤奖、累计项目收益 | 播放奖和累计项目收益可配置不同阶梯区间奖励；不改奖励计算和发放逻辑 |

## 从截图观察到的现有呈现

- 后台配置分为「基础信息」「活动规则」两步，右侧为移动端前端预览。
- 移动端头部为方形封面、活动名称、活动时间、浏览/参与人数、标签；示例中名称和时间存在截断。
- 头部下方有中奖提示区域，主体包含「介绍 / 案例 / 榜单」Tab。
- 介绍支持长富文本，包括标题、段落、强调色、表格、图片和链接；不同介绍模块在同一内容流中接续展示。
- 案例按标题分组，下方展示图片和视频。截图不足以确认点击后的图片预览、视频播放细节。
- 榜单按行呈现名次、头像、脱敏昵称、数值、小字描述和周期描述，前三名有突出样式。
- 多张预览底部显示两个按钮；即使当前选中案例或榜单 Tab，截图中仍可见按钮。

## 截图中需要与实际现状核对的细节

以下是截图中的界面说明或样例，并非本次功能变更要求：

- 后台文字提示介绍需标题与内容完整、案例需完整才下发；榜单开启后即展示 Tab，空榜显示空态。
- 按钮区域的后台说明写「仅介绍 Tab 展示」，但截图在案例、榜单 Tab 中也显示底部按钮，资料存在不一致。后续以现有实际行为为准，不在本次擅自调整。
- 非跳转按钮出现「点击后变更文案」字段，用户补充未说明其具体状态与行为，需沿用现状并补充核对。
- 全勤奖截图包含每日有效稿件、连续打卡天数、全勤奖金；累计项目收益规则包含品牌项目、其他业务项目和名次阶梯；阶梯奖励样例含奖金与实物礼品。截图样例中的具体值不作为统一规则。
- 当前提供的是后台及移动端预览，尚无现有 PC 列表/详情截图，不能据此判定 PC 当前交互。
- 首页前 3 个活动如何选取、如何排序，以及「已参与」状态的现有判定口径需核实；本次展示沿用既有业务和数据能力，不新增规则。
- 活动详情抽屉中各类配置的 PC 信息组织与响应式呈现属于后续 UX 设计内容，本说明不预设方案。
