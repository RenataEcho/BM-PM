## 3. 最后覆盖决定基线

以 `.memlog.md` 最后有效记录为准：

- 「所属导师团」只展示当前社群正在关联的导师团；导师的其他导师团归属不在该社群卡片展示。
- 一名导师可同时归属多个导师团，这是全局组织关系，不改变社群卡片的单团展示。
- 导师团允许暂未配置导师长；没有导师长时隐藏负责人分区。
- 社群负责导师与导师团成员均使用后端成品顺序，前端不再排序。
- 导师团成员缺少主身份时，由后端归入末尾「其他」分组。
- 导师团主页数据使用打开或刷新时的当前有效快照。

## 4. 逐项复核

### 4.1 卡片只展示当前社群导师团

**判定：通过。**

`prd.md` 已明确：

- 「所属导师团」只展示当前社群正在关联的导师团。
- 不展示该导师同时归属但未服务当前社群的其他导师团。
- 当前社群最多关联一个当前有效导师团，因此每张负责导师卡片至多展示一个导师团项。
- 当前社群没有有效导师团，或该负责导师不属于当前导师团时，显示「暂无」且不提供主页入口。
- 后端异常返回多个有效导师团时，前端不自行选择，显示异常提示。

`需求单.md` 的 2026-11-06 导师团补充、`addendum.md` 的导师团边界及 `.memlog.md` 最后覆盖决定均与此一致。

### 4.2 导师可多团全局归属

**判定：通过。**

`prd.md` 同时保留两个不同层级的规则：

- 全局关系：一名导师可同时属于多个导师团。
- 当前社群卡片：只显示当前社群正在关联的导师团。

导师团主页只按当前主页对应的导师团 ID 展示成员；同一导师只要与当前导师团的归属关系有效，就可出现在该团主页。该规则没有把“全局多团归属”误改为“社群卡片展示多团”。

`需求单.md`、`addendum.md` 和 `.memlog.md` 的最后覆盖记录均作出了同样区分。

### 4.3 无导师长时隐藏负责人分区

**判定：通过。**

`prd.md` 已将导师团定义改为由“零或一位导师长”组成，并在 FR-17 明确：

- 已配置当前有效导师长时，展示「导师团负责人」分区。
- 未配置当前有效导师长时，不显示该分区。
- 其他导师仍在「导师团成员」分区正常展示。
- 后端异常返回两位及以上有效导师长时，前端不自行选择，负责人区显示「导师长信息异常」。

`需求单.md` 和 `.memlog.md` 最后覆盖决定一致。`addendum.md` 未重复描述该页面状态，但没有相反规则。

### 4.4 后端成品排序

**判定：通过。**

社群负责导师：

- 后端按后台配置生成唯一成品顺序。
- 前端严格按返回数组顺序展示。
- 前端不把导师长置顶，也不按身份名称或层级重新排序。

导师团成员：

- 后端返回身份分组的成品顺序。
- 后台身份层级仅用于后端生成顺序。
- 同一分组内严格采用后端返回数组顺序。
- 缺少主身份的成员由后端归入最后一组「其他」。
- 前端不硬编码身份种类、分组先后或组内顺序。

因此，早期“导师长固定首位、前端按身份层级排序”的规则已被正确收窄和覆盖：导师长若存在，单独显示在负责人分区；普通成员分组与排序都由后端给出成品。

### 4.5 统计快照一致性

**判定：通过。**

`prd.md` 已定义「当前有效快照」：

- 在打开或刷新导师团主页时由后端按同一时点生成。
- 同一次响应中的基本信息、导师长、成员、三个统计指标和介绍使用同一个导师团 ID。
- 页面停留期间不混入新快照；主动刷新后整体切换到新快照。
- 导师团成员列表与导师团成员数使用同一快照。
- 三个统计指标由后端按同一快照返回，前端不从可见列表自行推算。

三个指标口径一致且可验收：

- 服务社群数：当前有效服务社群按社群 ID 去重。
- 导师团成员数：当前有效导师按导师 ID 去重，包含导师长。
- 服务会员数：当前服务社群中尚未退出或移除的会员按会员 ID 跨社群去重，并排除存在当前有效导师记录的会员 ID。

PRD 还给出了 G1 的计算样例，结果与上述口径一致。

### 4.6 空态一致性

**判定：通过。**

各空态已按对象区分，未把“缺失”误显示为数值 0：

- 所属导师团：无当前有效导师团或导师不属于当前团时显示「暂无」，不提供入口。
- 多条当前有效导师团：显示「导师团信息异常，请稍后再试」，不自行选择。
- 导师团图标：显示默认占位图标，并提供可读替代文本。
- 导师团名称、负责赛道：未返回时显示「暂无」。
- 导师团不可用或请求失败：显示「导师团暂不可用」，不展示上一导师团缓存。
- 未配置导师长：隐藏负责人分区。
- 多位有效导师长：显示「导师长信息异常」。
- 成员头像：使用默认头像并提供可读替代文本。
- 成员昵称、身份、职责：字段保留并显示「暂无」。
- 无导师长以外成员：保留成员分区并显示「暂无成员」。
- 统计值明确为 0：显示 0。
- 统计指标未返回：显示「暂无」。
- 导师团介绍为空：保留分区并显示「暂无介绍」。

这些场景与 `需求单.md` 的“0 与未返回分开”“无导师长隐藏负责人分区”一致，也完整承接 `.memlog.md` 的最后决定。
