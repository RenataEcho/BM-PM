## 3. 详细差距

### G1（高）`frontend-rules.json` 未完整同步 2026-11-02 三项决策

- 导师规则只写「头像、名称默认可编辑」，没有写保存后用户视角导师团列表和导师浮层必须同步最新头像、昵称。
- 战绩规则仍以固定内容描述社群战绩和成员排名，没有写社群战绩、收益荣誉榜由后端分别控制，也没有写单项关闭、双项关闭以及「社区战绩」Tab 的隐藏行为。
- 排序规则只写「第一个显示导师团负责人」，没有写其余导师按身份上下级从高到低、同级沿用后端返回或配置顺序。

影响：该文件是 Demo 左侧规则和本地规则编辑的直接输入，若按它实现或验收，会漏掉本轮三个核心变更。

### G2（高）`addendum.md` 的旧身份样例可能被误当成固定排序

`addendum.md` 仍以「一位创业导师和若干助理导师」描述现有画面，未说明这只是历史画面样例，不能据此把创业导师、助理导师硬编码为排序层级；也没有记录导师长固定首位、其余按身份上下级、同级按后端顺序。

`prd.md` 已明确禁止前端硬编码「创业导师优先、助理导师随后」，因此实现时应以 PRD 为准。

### G3（中）关键对象存在多组术语漂移

- 可编辑名称：`昵称`、`导师名称`、`名称`、`名字` 混用。建议统一为「昵称」；「飞书昵称」仅用于飞书同步字段。
- 浮层：`导师浮层`、`导师详情浮层`、`浮层` 混用。建议统一为「导师浮层」。
- 列表：`导师组`、`导师团列表`、`社群导师` 混用。建议产品对象统一为「社群导师列表」，页面 Tab 保留「社群导师」。
- 身份展示：`身份`、`标签`、`身份 tag` 并列出现。PRD 的准确定义是「身份是导师后台配置的标签」，前端只需显示一个身份标签，不应理解为两个字段。
- 排名模块：`成员排名`、`成员TOP-10`、`收益荣誉榜` 混用。建议需求对象统一为「收益荣誉榜」，并注明它沿用原「成员TOP-10」规则。
- 战绩区域：`社群战绩` 是模块名，`社区战绩` 是 Tab 标题，二者不应互换。

PRD 内部也有一处轻微漂移：术语定义中的「导师基础信息」写了「名字」，而其他最新规则使用「昵称」。本次遵守约束未修改 PRD。

### G4（中）`frontend-rules.json` 含有超出或偏离 PRD 的旧规则

- 「统计口径按现有逻辑」与 PRD 的「统计口径待确认、页面按返回值原样显示」不一致，可能误导实现方自行沿用未定义的旧统计逻辑。
- 「导师介绍与……管理后台配置的使用同一份内容」扩展了数据同源范围；当前 PRD 只确认导师端「个人介绍」与用户视角导师浮层「导师介绍」使用同一份内容，没有确认另一个管理后台配置入口。

### G5（中）收益榜与“不做月收益排行榜”的边界不够清晰

`addendum.md` 和 `需求单.md` 写品牌参照页的「月收益排行榜」不做；最新 PRD 又要求展示「收益荣誉榜（原成员TOP-10）」。两者可以是不同模块，但输入中没有统一说明，存在把收益荣誉榜误删为非目标的风险。

建议后续非 PRD 输入明确：不做的是品牌参照页的「月收益排行榜」；本需求要做的是「收益荣誉榜」，沿用原成员 TOP-10 规则。

### G6（低）决策日志与 PRD 元数据状态不一致

`.memlog.md` 曾记录「PRD finalized、status 为 final」，当前 `prd.md` 头部状态却是 `draft`。后续变更可能使 PRD 重新进入草稿，但日志没有记录这次状态回退。该问题不影响三项业务规则，但会影响评审方判断文档是否已定稿。

另外，`.memlog.md` 的历史段落保留了「创业导师优先、助理导师随后」「头像和名称仅展示」等旧口径；后文已有 `override` 明确覆盖，作为追加式日志可以保留，但读取时必须以最后一条覆盖记录为准。

## 4. 建议统一口径

- 可编辑字段：头像、昵称、个人介绍。
- 保存同步：保存成功后，用户视角的社群导师列表和导师浮层使用最新头像、昵称；导师浮层同时使用最新个人介绍。
- 排序：导师长固定首位；其余按后台身份上下级从高到低；同级按后端返回或配置顺序；前端不硬编码具体身份名称。
- 战绩控制：社群战绩、收益荣誉榜是两个独立模块，分别接受后端开关；单项关闭只隐藏该模块；两项均关闭或最终均无内容时隐藏「社区战绩」Tab。
- 模块命名：需求对象称「社群战绩」「收益荣誉榜」；页面 Tab 标题称「社区战绩」。

## 5. 建议后续处理顺序

1. 优先补齐 `frontend-rules.json` 的三项最新规则，并清理「名称」「身份+标签」「按现有逻辑」等旧表述。
2. 在 `addendum.md` 中把创业导师、助理导师标成历史画面样例，并明确收益荣誉榜与不做的月收益排行榜不是同一模块。
3. 在 `.memlog.md` 追加当前 PRD 状态说明，消除 `final` 与 `draft` 的元数据冲突。
