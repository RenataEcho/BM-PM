# PRD: 国内项目优化

## 0. Document Purpose

本文只覆盖全局迭代 **FR-004「国内项目优化」**，业务线为右豹PC（`youbao-pc`）。读者用它约束同目录的 `DESIGN.md`、`EXPERIENCE.md`、`SPEC.md` 和 Demo。

正文里的 **FR-1、FR-2…** 只表示本增量第 n 条，不是全局编号。全局号写在 front matter 的 `iteration_id: FR-004`。

Demo 是 `demo/iteration/fr-004-domestic.html`，项目画面在 `demo/iteration/fr-004-domestic-demo.html`。输入是同目录 `需求单.md`。不并入其他迭代。

## 1. Vision

国内项目是创作者决定「今天做哪个项目」的列表。线上把分类放在一条藏滚动条的芯片里，等级含义要悬停才看得到，只有一种密表，接单结论要进详情才看得见。

本增量让分类完整露出，列表和宫格给出同一套等级、人数和收益，详情先给能不能接单和单价。配色沿用这一页现有的白底和红色点缀。提词、回填、开白、收益仍去原来的页面。

## 2. Target User

### 2.1 Jobs To Be Done

- **功能：** 在国内项目里按分类和关键词找到一个能做的项目。
- **功能：** 比较在做人数、顶尖月入和本周收益，再决定点哪一条。
- **情境：** PC 工作台，一次要看完一个分类里的多个项目。
- **情绪：** 不想在不能接单的项目上点进提词才发现被拦住。

### 2.2 Non-Users (v1)

- 只做海外故事、海外短剧的创作者。本增量不改海外故事页。
- 运营配置项目和结算的人。本增量没有新的后台页。

### 2.3 Key User Journeys

主角是创作者「林夏」，已经登录 PC 工作台。

- **UJ-1. 林夏在小说推文里按月入挑项目。** 她打开国内项目，分类默认小说推文，按顶尖月入从高到低看，点开番茄小说。抽屉写着已准备接单和结算单价。她点进入接单。实现 FR-1、FR-3、FR-4、FR-5。
- **UJ-2. 起点读书不能接。** 她点开起点读书，看见「项目名额已满」，进入接单是灰的。她关闭抽屉，改选下一条。实现 FR-6。
- **UJ-3. 搜索没有结果。** 她在小说推文里搜一个短剧名，列表说明当前分类没有匹配，并可以清空搜索。实现 FR-2。
- **UJ-4. 盐言故事要回填。** 列表和抽屉都有回填。不需要回填的项目没有这个按钮。实现 FR-4。

## 3. Glossary

- **国内项目：** `/yb/order-center/domestic`，区域固定为国内的项目列表。
- **分类：** 小说推文、短剧、故事会等芯片。默认落在小说推文。
- **等级：** 项目分成档，如 S · 70%。悬停或抽屉里能看到完整说法。
- **可接单：** 当前用户可以进入接单。否则必须给出原因。
- **回填：** 只有项目要求回填时才出现。
- **开白：** 只有项目要求官方开白时才出现「去开白」。

## 4. Features

### FR-1 分类完整露出

分类换行排列，每一类都显示名称和项目数。不把多出来的分类藏进无滚动条的一行。

- **Consequences：** 八个示例分类在 1280 宽的内容区里不用横向拖动就能看见至少第一行全部，换行后的分类仍可点。选中态不依赖危险红。

### FR-2 当前分类内搜索

搜索框占位仍是「搜索项目名称 / 标签」。只过滤当前分类。没有结果时说明是哪个分类、哪个词，并提供清空。

- **Consequences：** [ASSUMPTION] 在小说推文中搜索「红果短剧」得到空状态，而不是跳到短剧分类。清空后恢复该分类列表。

### FR-3 列表可扫、可排序

每一行给出项目名、标签、等级和分成、在做人数、顶尖月入、本周收益和涨跌。在做人数、顶尖月入、本周收益、等级可排序。收益和上涨沿用线上红色 `#f56c6c`，下跌沿用绿色 `#67c23a`，持平用灰色。不可接单在行上标出。

- **Consequences：** 不打开详情也能看出哪条月入更高、哪条现在不能接。排序切换后从第一页重新排。

### FR-4 行上的动作

行上保留详情、提词。需要回填才显示回填。点击项目名或详情打开抽屉。提词、回填、开白、收益离开本页，Demo 只提示目的地。

- **Consequences：** 七猫小说没有回填按钮。知乎故事有回填按钮。星图品牌短剧的抽屉里有去开白。

### FR-5 详情先给结论

抽屉顶部是可接单或原因，接着是在做人数、顶尖月入、本周收益、我的收益和结算单价。主按钮是进入接单。项目详情、提词说明、回填规则、结算说明、特别说明仍在页签里。

- **Consequences：** 打开番茄小说时，不切页签也能看见单价和进入接单。五段说明仍可切换，空内容写「暂无内容」。示例数据都有说明。

### FR-6 不可接单

原因来自现有资格，例如名额已满、等级不足、需先开白。进入接单不可点。关闭后回到原列表和原分类。

- **Consequences：** 起点读书的进入接单为禁用。关闭后仍停在小说推文，不改搜索和排序。

### FR-7 列表与宫格

顶栏提供「列表 | 宫格」。两种模式使用同一批项目、同一套筛选、排序、分页和详情抽屉。宫格卡片展示的字段和动作与列表行一致：详情、提词，以及按需的回填。切换模式不重置分类、搜索词、排序和当前页。

- **Consequences：** 在宫格里点番茄小说，打开的抽屉与列表模式相同。知乎故事的宫格卡片有回填，七猫小说没有。

## 5. 非目标

- 不改海外故事页，也不在国内项目里提供海外切换。
- 不重做提词、回填、收益、开白页面。
- 不新增后台配置，不改结算和资格规则。
- Demo 不接真实接口、登录和持久化。
