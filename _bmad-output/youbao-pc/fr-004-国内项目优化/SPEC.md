# FR-004 · 国内项目优化 · SPEC

## 范围与优先级

`DESIGN.md` / `EXPERIENCE.md` 优先于 `prd.md`，再优先于 Demo。冲突时改 Demo。

业务线右豹PC。全局号 FR-004。状态待开始。无新后台页。

## 数据合同

列表项必须能定位项目，并带分类、名称、标签、等级、分成比例、在做人数、顶尖月入、本周收益、涨跌方向和文案、是否可接单、不可接单原因、是否要回填、是否要开白。

详情另带我的收益、结算单价（类型、说明、单价）、提词有效期，以及项目详情、提词说明、回填规则、结算说明、特别说明。Demo 使用固定示例，不请求线上接口。

## 行为合同

- 国内项目不提供海外切换。
- 分类全部可见、可换行。选中一个分类后，搜索只作用在该分类。
- 在做人数、顶尖月入、本周收益、等级可排序。默认顶尖月入降序。
- 列表和宫格共用上述数据和动作。切换不重置筛选、排序和页码。
- 行操作是详情、提词，以及按需的回填。
- 抽屉先展示接单结论、四项数字和结算单价，再展示五段说明。
- 可接单才能进入接单。不可接单展示原因并禁用主按钮。
- 去提词、去回填、去开白、查看收益沿用原页面，本增量不定义那些页面的内部步骤。

## 验收

- 小说推文默认可见，分类换行后仍可点到网盘、知识、游戏、工具。
- 按顶尖月入排序时，番茄小说高于掌阅小说。
- 起点读书进入接单不可点，原因是项目名额已满。
- 知乎故事有回填，七猫小说没有。
- 星图品牌短剧有去开白。
- 在小说推文搜索一个不存在的词，出现空状态；清空后列表恢复。
- 切到宫格后，仍是当前分类和当前排序；卡片上的详情、提词、按需回填与列表行一致。
- 需求规则只写本需求。业务流程见页内流程图。全屏预览能打开并退出。
