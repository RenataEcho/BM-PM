# FR-004 · 国内项目优化 · DESIGN

业务线：右豹PC。迭代外壳沿用 `docs/design/iteration-shell/` 和 `demo/iteration/component-spec-demo.html` 的按钮、抽屉、页签、流程图，不把外壳的蓝紫画进项目页。

项目页沿用线上国内项目的白底和 Element 点缀，不另起品牌橙、青绿或落地页配色。选中、收益、上涨和「详情」描边继续用 `#f56c6c`。下跌用 `#67c23a`。标签继续用 `#fdf6ec` / `#e6a23c`。

## 色彩

| 用途 | 色值 |

| 页底 | `#f5f7fa` |
| 卡片 | `#ffffff` |

等级字号跟在分成比例旁边，例如「S · 70%」，不再只留一个要悬停才看懂的代号。

## 字与间距

这是 PC 内容区，正文 14px，页标题 20px / 700，表头 12px。数字用等宽数字。间距 8 的倍数。圆角：芯片和浏览切换 8–10px，卡片 8px，按钮 8px。

## 布局

- 顶栏：面包屑、标题「国内项目」、当前分类的结果句、浏览切换、搜索、刷新。
- 浏览切换是「列表 | 宫格」。两种模式共用分类、搜索、排序、分页和同一张详情抽屉。
- 分类在顶栏下面，`flex-wrap`，不隐藏溢出。
- 列表是表现有列：项目、等级、在做人数、顶尖月入、本周收益、操作。
- 宫格是四列卡片。卡片里是项目名、标签、等级和分成、在做人数、顶尖月入、本周收益和涨跌，底部动作与列表行相同。窄屏降为三列、两列。
- 宫格没有表头，排序放在卡片上方的一排按钮，规则与列头排序相同。
- 详情抽屉从右侧盖上，宽 440px。
- 主按钮「进入接单」在抽屉底栏右侧。

## 不采用的检索配色

设计检索给出的青绿主色和落地页结构不用于本页。本页是工作台列表，不是营销首页。
