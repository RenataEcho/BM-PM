# 快捷图标 — Experience Spine

四个金刚区入口的行为。视觉以 `DESIGN.md` 为准。

## Foundation

手机上一行快捷入口。视觉身份见 `DESIGN.md`，底板与字号继承 `docs/design/移动端设计规范.md` 的金刚区，不另做一套组件。

## Information Architecture

| 表面 | 从哪来 | 做什么 |
|---|---|---|
| 快捷行 | 首页卡片内 | 四个入口并排，点进对应内容 |

从左到右固定为：新手必看、项目教学、推文教程、海外课程。

点进去的页面还没定，本刀不发明落地页。

## Voice and Tone

| 入口 | 可见标题 |
|---|---|
| 第一列 | 新手必看 |
| 第二列 | 项目教学 |
| 第三列 | 推文教程 |
| 第四列 | 海外课程 |

标题就是这八个字的四组，不加「点击查看」一类说明。

## Component Patterns

| 组件 | 行为 |
|---|---|
| 快捷列 | 图标和标题同属一个点击区。点图标或点标题，结果相同。 |
| 快捷行 | 四列等分，顺序不随账号变化。没有选中态，它们是入口，不是 Tab。 |

## State Patterns

| 状态 | 表现 |
|---|---|
| 默认 | 四列都可点 |
| 按下 | [ASSUMPTION] 整列透明度降到 0.72，松手恢复。没有选中留存。 |

## Interaction Primitives

点按一列即离开当前卡片、进入该入口。本刀不定义进入之后的页面。

## Accessibility Floor

每一列的无障碍名称等于可见标题：新手必看、项目教学、推文教程、海外课程。不只靠颜色区分。点击区不小于图标加标题的整列。

## Key Flows

[ASSUMPTION] 主角是刚打开首页的创作者小周。

1. 小周在首页看到一行四个方圆图标，下面各有四个字。
2. 她要先看入门内容，在「芽苗」和「新手必看」上对上号。
3. **高潮：** 她分得清另外三列——文件夹是项目教学，气泡是推文教程，地球是海外课程——然后点中「新手必看」。
4. 进入之后去哪，本刀未定。

## Open Questions

- 四个入口各自打开哪一页。
- 芽苗 / 文件夹 / 气泡 / 地球这四个符号是否要换。
